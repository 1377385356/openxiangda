Make connected development the default application loop: start local Web and
Nest hot reload behind a loopback proxy, authenticate remote Data API and local
App API requests with the platform developer Dev Session, prefer test data,
and keep production warnings visible. Fresh workspaces no longer inherit local
runtime artifacts, and application code receives the platform-validated
multi-role current user without an active RoleSession.

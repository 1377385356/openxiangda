从业务想法开始时，先阅读[对话发现与产品设计](./product-design.md)，形成设计基线后再制定实施计划；页面方案参考[交互模式](./interaction-patterns.md)。首次使用工具阅读[安装指南](./getting-started.md)。已有项目先查看本地版本和上下文，再按[开发流程](./development.md)修改。

[模型与标准 CRUD](./application-foundation.md)、[字段组件](./field-components.md)、[数据与权限](./data-authz.md)覆盖常见应用；[匿名公开访问](./public-access.md)服务没有平台账号的外部访客。标准[审批与通知](./workflow-events.md)由平台执行。复杂规则可使用[按需后端](./backend.md)。

交付前阅读[校验与验收](./testing.md)，再执行[测试部署和生产晋级](./delivery.md)。版本更新后按[升级指南](./upgrading.md)刷新项目资料与 MCP 进程。

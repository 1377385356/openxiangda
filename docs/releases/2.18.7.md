# OpenXiangda 2.18.7：模块视图查询选择放行 system 字段（GAP-MODULE-003）

模块视图的筛选/搜索/排序/分组选择可以引用 system 字段，与低层 data.resources 的 system+filter 语义对齐；展示与可写选择维持拒绝。devkit-core 2.16.0 携带实现。

## 新增能力

- crud[].list 的 filterFields/searchableFields/sortableFields/defaultSort 与 sections.fields 允许引用 system: true 字段：外键标识（activityId/routeId/campaignId 等）与归属快照（memberUser 等）不再阻塞模块化迁移。
- 声明速查新增对应规则条目。

## 修复问题

无。

## 受影响用户

- 从 data.resources 迁移到模块化声明、存在大量 system+filter 字段的应用（如数智工会 szgh-v2 的 40/74 资源）。

## 升级步骤

- 应用精确依赖升级到 openxiangda 2.18.7（openxiangda-devkit-core 2.16.0）后重新运行 check 与部署。

## 已知限制

- 展示与可写选择（list/form/detail.fields）仍不接受 system 字段——按 GAP 文档期望保留现行限制。

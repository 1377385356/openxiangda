# 匿名聚合查询与工作流作者体验

为匿名公开门户提供固定维度、度量和排序的有界聚合查询，并包含已评审的工作流作者体验改进。

## 新增能力

- 匿名 public.query 支持固定 aggregate dimensions、measures 和 order，并复用 publicFilters、Native RLS 与有界分页。
- 工作流作者体验改进随同一正式七包组合发布。

## 修复问题

- compiler、bundle、JSON Schema 和 server execution 对匿名聚合查询保持同一闭合合同。

## 受影响用户

- 需要匿名首页统计、分类、学院分布或排行的 OpenXiangda V2 应用。

## 升级步骤

- 升级同一正式发行组合；在 TEST/preproduction 验证匿名聚合、游标、权限和浏览器性能。

## 已知限制

- 本地门禁不代表学校站点已安装该平台组合。

## 关联 Issue

无。

## 兼容要求

- node: Node.js 24 or newer for maintained toolchain
- generation: OpenXiangda V2; V1 unchanged
- platform: anonymous-public named and aggregate queries 1.1.0; existing public list/read policies remain compatible

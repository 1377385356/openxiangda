# OpenXiangda 2.73.0

在 2.72.0 匿名具名查询基础上，加入固定维度、度量和排序的匿名聚合查询合同，并包含已评审的工作流作者体验改进。

## 新增能力

- 匿名公开查询支持固定 aggregate dimensions、measures 和 order，并复用 publicFilters、Native RLS 与有界分页。
- 发行组合包含工作流人员来源和条件选择展示改进。

## 兼容要求

- node: Node.js 24 or newer for maintained toolchain
- generation: OpenXiangda V2; V1 unchanged
- platform: anonymous-public named and aggregate queries 1.1.0; existing public list/read policies remain compatible

## 已知限制

- 本地门禁不代表学校站点已安装该平台组合；需在 TEST/preproduction 完成真实浏览器和权限验收。

# 大子表分页与整表校验

PC与手机主子表每页渲染十行，保留完整输入、草稿、排序和整单提交；校验覆盖全部行。

## 新增能力

无。

## 修复问题

- 减少大子表同时挂载的编辑控件；未显示行继续复用标准字段规则校验，任务完成的错误定位到对应页。
- 跨页移动使用绝对行序号，上传和待重试文件未处理时保留当前页。

## 受影响用户

- 使用V2标准主子表、流程发起或任务办理页面的用户。

## 升级步骤

- 升级精确SDK/CLI并重新构建应用；本修正不引入服务端迁移或数据格式变更。
- 本任务仅本地包消费与合成验证，不执行npm发布。

## 已知限制

- 分页是渲染边界，数据和事务仍遵守原先每表100行、声明合计400行等预算。
- 最大附件组合与学校完整源流程运行验收仍单独验证。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- platform: 沿用2.48.0匹配平台；1.x不消费此组件

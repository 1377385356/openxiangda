# OpenXiangda 2.21.4：移动 px 测量样式执行顺序修复

将 Ant Design Mobile 的最小 px tester 测量样式前置到直接加载移动组件的 CSS side-effect prelude，修复 Vite 依赖优化后组件模块早于 JavaScript 初始化器求值而产生的启动告警。

## 新增能力

无。

## 修复问题

- openxiangda/react 与 openxiangda/mobile 的移动组件图会在 Ant Design Mobile 首次 px 测量前加载最小运行时 CSS，真实 Vite 浏览器入口不再出现 antd-mobile Global px tester 告警。
- 新增真实 Chromium 回归门禁，验证两个 px tester 均为 fixed，10 px tester 的测量高度为 10 px，并继续拒绝 html、body、链接、按钮与主题全局重置。

## 受影响用户

- 使用 OpenXiangda 2.0 React 或移动组件，并在 Vite 开发模式控制台仍看到 antd-mobile Global px tester 告警的应用开发与维护会话。

## 升级步骤

- 将应用对 openxiangda 的精确依赖升级到 2.21.4，并按锁文件重新安装依赖。
- 重新启动 Vite 开发服务器以刷新依赖优化缓存；业务应用不应新增 antd-mobile 依赖或临时导入上游 global 入口。

## 已知限制

- 本修复只调整浏览器模块求值前的测量 CSS，不改变应用主题、移动页面布局、业务组件样式或平台服务端。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: 无需 platform-server 配套升级；浏览器应用需升级 openxiangda 并重新启动开发服务器。
- v1: V1 工作区与维护引擎不受影响。

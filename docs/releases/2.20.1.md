# OpenXiangda 2.20.1：contracts 资源级审计列排序修复

openxiangda-contracts 修复资源级 surface list defaultSort 对平台审计列（created_at/updated_at 等）的 fail-closed 误拒：与命名视图 defaultSort、Data API order 的系统列规则对齐。devkit 与 openxiangda 2.20.0 已含的行为不变。

## 新增能力

- 资源级 surface list defaultSort 支持平台审计列（created_at/updated_at/created_by/updated_by/id/revision），不再按未知字段 fail-closed；补回归测试。

## 修复问题

无。

## 受影响用户

- 所有使用数据策略、行级权限、匿名公开访问的 OpenXiangda 2.0 应用开发者与 AI 开发会话。

## 升级步骤

- 应用把 openxiangda 精确钉扎到 2.20.0 并重跑 pnpm openxiangda check；出现新告警/报错时按提示调整策略声明。
- 使用 created_by 行规则需平台服务端配套版本；升级前请确认平台列车已包含该修复。

## 已知限制

- created_by 行规则的运行时 WITH CHECK 正向匹配修复仍随平台列车交付。

# OpenXiangda 2.31.9：审批凭据绑定与附件预览修复

修复登录面刷新后既有审批凭据失配，以及流程附件预览遗漏 CSRF 请求头的问题。

## 新增能力

无。

## 修复问题

- 工作流操作保留签发详情时的 CSRF 绑定，登录面刷新不会将已签发操作错误地改用新凭据。
- 流程附件元数据、封面缩略图与文件内容通过 SDK 携带所需请求头，保留实例和字段授权。
- 审批确认弹窗持续展示操作失败提示，便于用户了解未完成状态。

## 受影响用户

- 使用任务或实例审批、流程附件预览的 V2 应用。

## 升级步骤

- 升级 openxiangda 至 2.31.9 并重新构建应用，CLI 同批次更新模板依赖。
- 发布后核对真实审批提交、业务状态回读和封面预览；不需要修改角色权限或数据库。

## 已知限制

- 网络结果不明的写操作不会自动重试，应先查询原操作状态。
- 原始文件 URL 仍不代替带授权头的 SDK 文件预览，HTML 等附件的服务端隔离策略保持不变。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: 沿用既有工作流 Surface、一次性命令凭据与文件授权契约，无服务端放宽。
- v1: 独立 V1 引擎不受影响。

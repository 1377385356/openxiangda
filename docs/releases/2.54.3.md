# 主子资料删除容量说明对齐

同源开发者资料说明平台根记录加400条后代的有界删除能力，SDK请求形式保持。

## 新增能力

无。

## 修复问题

- 修正删除说明中旧100行上限，补充401行总量、嵌套共用预算、末行核对以及普通管理员100项边界。

## 受影响用户

- 已显式开启资料维护删除、需要删除多张owned子表的V2应用。

## 升级步骤

- 同步同源CLI/Skill使用资料，并使用已落实共享400行后代预算的平台Server；在本地验证资料授权与实际业务。

## 已知限制

- 仍只支持零个或唯一根关联实例；待启动、多流程和明细其他关联阻塞。关联流程最多100条、深度8及原字节/超时预算保持。
- 普通管理员公开请求仍最多100项，只有服务器核对的内部DELETE集合可展开至总401条；请求不能自行扩大预算。
- 本批不发布npm；源码及隔离数据库验证不能替代真实App六组、双端和103条源流程验收。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- platform: data.workflow-record-deletion@1.0.0，Server owned删除预算从共享DATA_SUBTABLE_MAX_TOTAL_ROWS派生。

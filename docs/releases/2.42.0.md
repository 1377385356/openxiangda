# OpenXiangda 2.42.0：任务私有草稿

当前任务处理人可以私有暂存不完整的标量输入，正式补填、同意或重提时沿原流程命令消费草稿。

## 新增能力

- 公开 SDK 支持本人任务草稿的保存、读取和按修订删除；PC 与手机共用确认采用、并发核对与原保存结果恢复。
- 任务私有草稿和通用表单草稿共享原有容量与保留规则。

## 修复问题

- 通用 CRUD 草稿接口明确隔离任务草稿，草稿不授予业务写入权。

## 受影响用户

- 使用代码任务页面的 V2 应用、当前任务办理人和 SDK 页面开发者。

## 升级步骤

- 部署配套的正式 SQL 和服务端实现；Native2 自动提供 workflow.task-private-drafts@1.0.0，无需配置开关。
- 本轮消费同批本地包并重启应用，不发布 npm。
- 页面字段显隐、只读和必填规则继续由应用代码维护。

## 已知限制

- 本轮草稿仅支持代码任务页面的标量字段，附件和子表随后补足。
- 包含任务草稿期间，不可单独回退到缺少通用草稿隔离的旧服务端。
- 本地测试不代表学校生产迁移或 101 流程验收完成。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: workflow.task-private-drafts@1.0.0，正式迁移 AddWorkflowTaskFormDraftsV2。
- v1: 原 V1 引擎保持。

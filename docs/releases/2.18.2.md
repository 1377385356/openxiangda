# OpenXiangda 2.18.2：模块模型级详情路由声明（GAP-MODULE-002）

模块化声明支持资源级详情路由绑定（detailRouteCode），模型声明未知属性 fail-closed；devkit-core 2.15.0 携带投影实现，根包为依赖传播版本。

## 新增能力

- AppDataModelDeclaration 新增 detailRouteCode（desktop/mobile route code）：模块化声明可表达 Workflow 详情接管消费的资源级详情路由绑定，materializeApplicationModules 完整透传到输出资源；低层 data.resources[].detailRouteCode 语义与既有校验（user surface、单动态参数、read capability 对齐）不变。
- 模型声明上的未知属性不再被静默丢弃：投影输出 APP_MODEL_KEY_UNKNOWN 错误 diagnostic（指向 `modules[i].models[j].<key>`）并使编译失败。

## 修复问题

无。

## 受影响用户

- 从 data.resources 迁移到模块化声明、需要资源详情路由由 Workflow 详情接管的应用（如数智工会 szgh-v2）。

## 升级步骤

- 应用精确依赖升级到 openxiangda 2.18.2（openxiangda-devkit-core 2.15.0）后重新运行 check 与部署。

## 已知限制

- detailRouteCode 校验沿用既有资源级规则；本次不改变共享纯校验器字节，configuration-compatibility/v2 的 validatorDigest 不变。

## 关联 Issue

无。

- workspaceGenerations: v2
- platform: 无平台配合要求；contracts 共享校验器字节不变。
- v1: 不改变 V1 运行时或应用。

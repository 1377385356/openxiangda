# OpenXiangda 2.41.0：任务页面补填与原命令提交

代码页面声明补填规则，普通审批人在当前任务中提交业务资料，再以同一事务完成审批或重提。

## 新增能力

- taskPages 与 taskPageCode 作为不可管理员覆盖的页面合同。
- save_form 保存补填但保留任务；approve/resubmit 支持 form 和记录 CAS。
- PC、手机与 SDK 共用表单、未知请求重试和重载后的原回执查询。

## 修复问题

- 已确认任务提交与后续资料刷新失败分开，回调仍能获取成功结果。
- 补填修改计算输入时清除当前失效输出，只允许确定重经生产者的 replay；历史步骤与签名不改。

## 受影响用户

- 需要审批补填、销假或退回重新核算的 V2 应用开发者与办理人。

## 升级步骤

- 平台安装正式 SQL 与 Workflow/Native 同批内核，自动提供 workflow.task-page-submit@1.0.0。
- 使用同批本地包并冻结 lockfile；本批不发布 npm。
- 由应用代码声明命名页面及字段规则，审批资格无需授予通用资源 CRUD。

## 已知限制

- 每定义16页、每页64字段、表单值64KiB；表达式8层/64节点。
- 草稿仍由 FormDraft 拥有，本批尚未开放任务草稿、附件与子表补填。
- 修改影响已计算步骤且不能经 replay 重算时明确拒绝；固定数据逻辑修订漂移也拒绝。
- 本说明不代表学校、生产或全量流程运行验收完成。

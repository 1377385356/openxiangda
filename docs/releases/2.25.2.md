# OpenXiangda 2.25.2：标准工作中心视图深链

标准工作中心可从 PC 或移动端链接直接打开我创建的、待我审批、我已处理或抄送我的视图。

## 新增能力

- 标准工作中心支持 view=created、pending、handled、cc 查询参数，切换标签时同步 URL。

## 修复问题

- 不支持的 view 参数回退到待我审批，不会传入 Workflow 列表请求。

## 受影响用户

- 使用 OpenXiangda 2.0 标准工作中心的 PC 和移动端应用；无参数入口仍默认为待我审批。

## 升级步骤

- 应用更新到 openxiangda@2.25.2 并重新构建发布后，可将我的申请入口链接设为 /work-center?view=created 或移动端 /m/work-center?view=created。
- 以目标环境的具名用户读取列表，确认视图数据仍由 Workflow API 的当前用户授权决定。

## 已知限制

- 此版不改变平台服务端授权、工作流数据或任何旧应用的现有链接；应用预发部署与具名角色验收需分别记录。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: 兼容已有 Workflow Work Center v2 API，无需服务端升级
- v1: 独立 V1 不受影响。

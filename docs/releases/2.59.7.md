# 多流程源码容量与自动抄送预算

统一多流程应用的路由和资源预算，修正标准详情子表展示，并让自动抄送在显式人数预算内支持最多200人。

## 新增能力

- 自动抄送可显式声明最多200人，未声明时仍默认20人；节点配置编辑器遵守原binding预算。

## 修复问题

- 浏览器路由校验与共享声明对齐2048路由、512资源，避免合法多流程应用被旧局部限制拒绝。
- 标准流程详情的PC子表与手机明细隐藏内部父关联、排序、hidden和system字段，保留业务值与顺序。

## 受影响用户

- 开发多流程V2应用、维护自动抄送节点或使用标准流程详情的开发者与管理员。

## 升级步骤

- 使用本批精确SDK组合，并同步支持新自动抄送预算的Server/Notification Hub；共享编译器摘要须一致。本候选先本地验证，未自动发布npm或学校生产。

## 已知限制

- 旧绑定与已运行实例不自动扩大人数；人工抄送仍最多20人，角色源最多200有效成员行，不能截断。
- 单实例历史仍受1000审批/自动抄送席位与2MiB读取预算约束。学校实际50人投递与性能尚未验。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- platform: 共享编译器同源配对；超过20人的自动抄送需同步升级Workflow与Notification Hub
- v1: V1不消费本批V2契约

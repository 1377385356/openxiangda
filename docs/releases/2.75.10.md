# OpenXiangda 2.75.10：国内正式下载与发布入口

V2 SDK 安装、升级、新应用和后端构建统一使用 npm.syedu.tech；xlsx 原始制品迁至同域名摘要地址，V1 更新渠道不变。

## 新增能力

- 正式 V2 发布目标固定为 Verdaccio，普通 npm 镜像环境变量不再改变发包目标。
- 新应用自动配置项目 registry，首次安装与 AI Skill 命令显式指定国内入口。

## 修复问题

- 去除新版 xlsx 依赖中的 GitHub 下载地址并固定原制品 SHA512。
- V2 版本查询与升级默认走国内源，V1 继续使用原渠道。

## 受影响用户

- OpenXiangda V2 CLI、React/Nest SDK 使用者及工具链维护者。

## 升级步骤

- npm install -g openxiangda@2.75.10 --registry=https://npm.syedu.tech/
- 已有 V2 项目在 .npmrc 设置国内 registry，运行 update install --target workspace，保留并核对锁文件。
- 已有后端 Dockerfile 对照官方模板增加 registry 环境配置；刷新 Skill 后完成应用自身验收。

## 已知限制

- npm 官方旧入口不会自动重定向；首次安装必须指定国内 registry。
- 历史 SDK 原始包保持原依赖地址，不保证历史版本所有 URL 依赖均可国内下载。
- 本次不自动修改或部署既有业务应用；特殊安装脚本的外部下载仍需独立治理。

# 按业务范围维护流程职责

成员管理支持有效审批与抄送流程中的范围职责，避免必须增加无关的数据策略才能维护审批人。

## 新增能力

- 范围目录返回有效流程绑定、兼容节点覆盖、补充路由和在途固定版本的职责来源。

## 修复问题

- SDK 成员选择器识别仅用于流程的范围角色，并继续按每条数据策略处理不受限角色排除。

## 受影响用户

- 按学院、部门等业务范围配置审批和抄送人员的 V2 应用开发者与管理员。

## 升级步骤

- 本轮导出同源的完整本地测试七包，不执行 npm 发布。
- 更新精确根包与配套依赖，并使用支持 Workflow 范围适用性的 V2 Server。

## 已知限制

- 职责范围维护不授予普通数据读写、应用管理或额外菜单权限。
- 已创建任务的参与人快照保持原语义；本地平台回归不代表学校真实流程验收。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- platform: 同源 Native 编译器与 Workflow 范围适用性服务；稳定 1.x 不受影响

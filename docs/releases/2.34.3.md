# OpenXiangda 2.34.3：显式长期只读繁忙恢复

允许热点详情等只读页面显式选择最长三十分钟恢复；默认两分钟策略及持久申请原期限保持，取消与真实故障仍及时结束。

## 新增能力

- 受管read、mine、result、allocation可显式设置budgetMs，超过120秒时最多恢复30分钟、120次请求；默认120秒和12次保持。

## 修复问题

- 长期读取仍冻结原输入、身份与权限视角，按原调用截止及Retry-After/抖动退避；AbortSignal中止请求和等待。
- 持久申请控制器显式保留原单次120秒上限，防止SDK扩展隐式改变既有受理和观察行为。

## 受影响用户

- 使用受管热点详情和持久排队能力的活动报名、预约及抢票应用开发者。

## 升级步骤

- 将应用openxiangda精确升级到2.34.3并刷新资料；应用按业务选择显式预算、离页取消及未结束窗口的固定截止。
- 验证繁忙恢复、真实网络/权限/依赖错误、身份切换和持久申请原期限后部署测试环境，目标硬件容量另外实测。

## 已知限制

- 仅已知只读繁忙恢复；不吞未知429、网络、权限或依赖失败，不自动重试写入。
- 客户端等待窗口不承诺服务端容量或最终处理时间，不代表已经受理或报名。
- 长期恢复不自动启用，普通Data API、平台后端与V1业务不变；刷新固定窗口由应用生命周期接入。

无。

- v1: V1引擎及业务不变。

# OpenXiangda 2.22.7：中文单字目录检索

PC 与移动目录选择器支持中文姓氏检索，避免单字输入被组件阻止发出查询。

## 新增能力

无。

## 修复问题

- 成员和部门选择器统一支持单个汉字，并保留普通关键词 2–64 字符约束及无效输入提示。

## 受影响用户

- 使用平台成员、部门选择器的 2.x 应用。

## 升级步骤

- 升级 openxiangda 至 2.22.7 并重建发布应用；服务端须包含 PL-20 单汉字目录检索修复（server 2bfd3e1）。

## 已知限制

- 不能仅升级应用而保留拒绝单字查询的旧平台后端；非汉字单字符仍不支持。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: server 2bfd3e1 或包含该提交的版本
- v1: 独立 V1 不受影响。

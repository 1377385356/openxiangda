# OpenXiangda 2.37.1：成员维护窄屏和提交状态修复

修复实际成员维护验收发现的默认侧边栏折叠、读取失败提示与保存期间按钮状态。

## 新增能力

无。

## 修复问题

- 默认应用 Shell 补齐响应式断点，小屏自动折叠侧边栏，为共享成员维护组件保留内容宽度。
- 成员读取失败和加载状态各自显示对应提示，避免把尚未读到的数据解释为空成员。
- 预览、提交和原编号重试期间显式禁用操作按钮，与关闭和草稿锁保持一致。

## 受影响用户

- 使用默认应用 Shell 或共享 RoleMembershipManager 的 V2 应用开发者和成员维护人员。

## 升级步骤

- 使用机器生成的同批 openxiangda 2.37.1、CLI 与依赖组合，更新冻结锁文件；本地可消费同批 tgz。
- 在窄屏和桌面核验角色筛选、成员核对、保存锁与未知结果恢复。

## 已知限制

- 自定义 Shell 仍由宿主负责可收缩内容宽度。
- 本次本地包修复不代表 npm 发布、M2 整体验收或学校生产迁移；字段行为由页面代码维护。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: 沿用原成员、代理和流程管理授权合同。
- v1: 沿用原 V1 分发。

# OpenXiangda 2.18.9：标准待办/消息中心视觉重构与自建中心合同收尾

修复运行时缺失基础字体导致的裸元素衬线渲染；待办中心与消息中心按统一页型重构（PC + 移动端）；nest 客户端补齐 work-center view 参数并新增应用自建待办/消息 UI 指南。

## 新增能力

- `OpenXiangdaPlatformClient.workflowWorkCenter` 新增可选 `view` 参数（`created/pending/handled/cc`），与浏览器端合同对齐；未传时保持 `status` 兼容行为。
- `docs/frontend.md` 新增「自建待办与消息中心 UI」：`openxiangda/core` 客户端用法、回执语义与标准路由不可接管等边界。

## 修复问题

- 运行时在 `.oxa-ui-root` 补基础字体/字号/行高兜底（读取 `--ant-font-family/font-size/line-height`），裸元素不再继承浏览器衬线默认值，应用品牌字体自动流入标准页。
- 待办中心改为 layout 底 + 内容卡层次：Typography 页头、Tabs 计数徽标、middle 密度表格、移动端吸顶页头与卡片精修。
- 消息中心控制区单行对齐（搜索/查询/仅看未读右对齐），摘要卡图标与数字层级、未读圆点显式主色、移动卡片未读左缘条。
- `verify-design-workbench` 改用探测的空闲临时端口，修复本机存在其他 Vite dev server（占用 5173）时设计门必失败的问题。

## 受影响用户

- 使用标准待办中心/消息中心的应用及其最终用户（视觉与可读性）。
- 需要服务端取 created/cc 待办视图或自建中心 UI 的应用开发者。

## 升级步骤

- 应用精确依赖升级到 openxiangda 2.18.9（及配套 openxiangda-cli/openxiangda-nest）后重新 build、check 与部署。
- 希望标准页跟随品牌字体/字号的应用在 `ui.theme` 中配置 token 即可，无需其他迁移。

## 已知限制

- Workflow 待办中心暂无渲染器替换钩子；需要完全不同呈现时按文档使用自有路由 + `openxiangda/core` 客户端自建。

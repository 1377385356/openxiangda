# 固定公开单选过滤的编译一致性修复

允许对 option.single 单选字段声明固定公开 eq 条件，保持平台强制过滤和字段白名单。

## 新增能力

无。

## 修复问题

- 修复是否开放、发布状态等单选字段被应用与 Native 编译器错误拒绝的问题。
- 单选值只接受字符串或 null，拒绝数组、对象、数值和布尔；多选、附件、人员及资源引用仍不接受。

## 受影响用户

- 通过 frontend.publicAccess 发布带开放/发布状态条件的公开目录应用。

## 升级步骤

- 应用升级精确 openxiangda 2.68.2 并重新 check；不修改已安装编译器或生成输出。
- 平台同步官方 openxiangda-contracts 2.88.1 编译器后再部署含此条件的应用；运行时过滤仍由平台负责。

## 已知限制

- 仍只允许固定 eq 条件；不开放匿名任意筛选、排序或普通 Native Data API。
- 包与平台发布不代表学校浏览器、真实角色或通知验收完成。

## 兼容要求

- node: Node.js 24 or newer for maintained toolchain
- generation: OpenXiangda V2; V1 unchanged
- platform: Native compiler openxiangda-contracts 2.88.1; server option JSON equality already implemented

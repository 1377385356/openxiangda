# OpenXiangda 2.20.4：Native 事件审计来源契约修复

严格接收平台已有的 Native 数据事件操作来源审计信息，避免具名业务动作和封存数据修复事件在处理器执行前被错误拒绝。

## 新增能力

无。

## 修复问题

- Native 事件 actor 显式支持有界 initiatedBy、businessAction 和 platformMaintenance；未知字段、凭据形字段和错误签名仍严格拒绝。

## 受影响用户

- 使用 Nest 订阅具名业务动作或封存数据修复所产生 Native 数据事件的 OpenXiangda 2.0 应用。

## 升级步骤

- 将应用精确依赖升级到 openxiangda 2.20.4，按锁文件安装并刷新工作区技能，验证后部署测试环境。
- 需要恢复的既有失败事件应核对原投递后使用正式 replay API，不重复提交业务动作。

## 已知限制

- 本修复不自动重放历史死信，也不替代应用真实角色、通知幂等和业务结果验收。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: 匹配现有平台 Native 事件生产者，无需服务端或数据库迁移。
- v1: V1 工作区与维护引擎不受影响。

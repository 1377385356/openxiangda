# 工具链事实契约兼容修复

保持现有 worker-effect 能力，并修复工作区工具链事实的公开契约。

## 新增能力

- 事件消费者支持受限查询、冻结事务、原键提交与回执恢复；平台统一执行并验证事件租约。

## 修复问题

- 允许工作区上下文返回已安装工具链事实。

## 受影响用户

- 需要定时业务事务的 OpenXiangda V2 应用开发者与平台维护者。

## 升级步骤

- 配对升级 SDK、CLI、共享契约和平台服务；为事件订阅显式声明 worker-effect 资源、字段及容量。

## 已知限制

- 投递至少一次，业务事务依赖原幂等意图去重；不允许工作流拥有的资源写入或任意业务身份冒用。

# 有界主子表容量与整单流程发起

标准流程可通过现有Field Kit填写并原子提交声明的主子表，任务办理和草稿共同支持源业务所需的50/350行规模。

## 新增能力

- 标准流程发起页支持声明子表；子行日期和零值沿字段编码，原命令保持整体提交与原结果恢复。
- 每表最多100行、父资源与任务页声明合计400行，完整替换保留旧行删除与新行意图。

## 修复问题

- 统一事务1000操作/2MiB、任务值1MiB和普通表单草稿2MiB预算；页面定义、状态及文件保持独立配额。

## 受影响用户

- 使用OpenXiangda 2.0主子表、标准流程发起和任务办理的开发者与用户。

## 升级步骤

- 先安装包含有界容量、标准主子表发起和正式授权增量迁移的匹配Server，再升级本批精确SDK/CLI并构建应用。
- 本任务仅本地打包及合成环境验证，不执行npm发布。

## 已知限制

- 一般child CRUD不提供跨所有写入者的父集合容量锁；标准整单提交与任务提交按各自受控事务验证。
- 最大附件组合仍受文件配额限制；本批容量能力不代表学校完整源流程通过运行验收。
- 产生大记录后应先停止新定义并处理在途；不能直接降级到旧49行runtime或截断数据。

- platform: 匹配的Native/BusinessProcess/Workflow/FormDraft运行时及增量SQL；1.x不消费这些契约

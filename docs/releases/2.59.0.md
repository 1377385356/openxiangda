# 托管查询断连恢复与流程表单能力更新

托管只读查询在认证传输层明确标记断连后沿原预算恢复；正式发行同时包含主线已评审的可选流程、子表及连接开发能力。

## 新增能力

- 流程支持发起人补正、具名业务补正命令、审批节点代理范围、批准后代理和原子Native阶段条件；新能力通过目标平台协商。
- owned子表支持最少行数、可信初始流程事实、具名只读展示和任务字段来源；资源关联支持显式绑定变化清空。
- 日期字段支持分钟精度，日期事件支持可信来源投影；大型应用声明与JSON节点预算可显式协商扩展。
- 连接开发支持普通浏览器登录身份与平台可信后台调用；新增纯表达式入口供浏览器和Node共享流程表达式。

## 修复问题

- read、mine、result、allocation的已标记连接中断与繁忙共用固定预算、尝试上限、退避及取消边界；已受理观察继续原结果，不延长首次提交截止。
- 修复受控子表字段联动、审批已确认任务转交后的页面继续和普通浏览器业务API的CSRF传递。

## 受影响用户

- 使用托管并发查询、标准流程表单、owned子表或普通角色连接开发的V2应用。

## 升级步骤

- 通过精确版本安装完整同源发行组合；启用新声明前核验目标平台能力。托管高并发应用需在真实浏览器与隔离压测中重新校准恢复行为。

## 已知限制

- 客户上一档万人HTTP请求图有29人结果观察被断连中断；后台全部终结但该档仍未完整通过。本版本的新万人复测尚未完成，既有最高完整通过为8000人HTTP请求图。
- 不自动重放业务写入，不将断连认定为已受理，不覆盖集中SSO登录或浏览器JS渲染容量；权限、依赖及未标记错误继续拒绝。
- 新增可选流程及普通角色源码调用需要配套平台能力；旧平台不能启用未支持的声明。

- v1: V1不消费本批V2运行时能力

# OpenXiangda 2.37.2：分配成员初始目录查询修复

共享成员维护组件在输入有效姓名或账号后查询分页目录，初次打开、清空或短词不再发出无效请求，已选人员标签保留。

## 新增能力

无。

## 修复问题

- 修复分配成员初始目录查询触发OPENXIANGDA_DIRECTORY_KEYWORD_INVALID的问题；搜索词至少2个字符或1个汉字、最多64个字符，保持分页、人员资格与当前用户授权。

## 受影响用户

- 使用RoleMembershipManager分配角色成员的管理员和V2应用开发者。

## 升级步骤

- 升级机器生成的同批openxiangda 2.37.2和CLI组合，更新冻结锁文件。
- 核验初次打开成员选择、搜索人员和清空搜索；本地实验室可使用同批tgz。

## 已知限制

- 目录搜索和成员维护仍受平台当前用户授权及有界分页约束。
- 本批本地修复不代表npm发布或学校生产迁移；字段行为由页面代码维护。

无。

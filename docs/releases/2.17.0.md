# OpenXiangda 2.17.0：一行声明生成用户端标准面

CRUD 视图声明 user: true 即可为普通用户生成“我的记录 + 提交”标准页面（桌面与移动双端），自动接线能力与登录落地，简单 CRUD 应用开箱即有完整用户端闭环。

## 新增能力

- resource-records / resource-submit 两种用户标准路由：/my/<resource> 与 /my/<resource>/submit（移动端 /m/ 前缀），能力分别绑定资源 read / create。
- “我的记录”标准组件：默认仅展示当前登录用户创建的记录（created_by 过滤）、分页、行详情抽屉与提交入口；提交页复用标准生成表单。
- 首个启用资源自动成为登录落地页与根路径；多资源用 user: { home: true } 显式指定；声明式 /home 占位仍可覆盖。

## 修复问题

- GenericResourceQuery 新增显式 createdBy 过滤映射 created_by 系统字段，不放宽其他系统字段查询。

## 受影响用户

- 为普通登录用户提供提交与查询的简单 CRUD 应用开发者。
- 使用 openxiangda 2.16 及以下的应用升级后行为零变化（未声明 user 面不受影响）。

## 升级步骤

- 应用精确依赖升级到 openxiangda 2.17.0 并刷新项目 Skill。
- 在需要用户端的 CRUD 视图上追加 user: true；如需自定义用户端体验，继续用自定义页面覆盖即可。
- 行级强隔离仍按数据与权限文档声明 dataPolicies；“仅本人”列表是展示过滤。

## 已知限制

- “我的记录”的本人过滤是查询层展示过滤，非服务端授权边界。
- 详情抽屉按声明字段只读渲染，暂不支持在用户端编辑已有记录（可继续用自定义页面）。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: 无需平台配合变更；路由与能力契约向后兼容。V1 引擎保持独立。
- v1: 不改变 V1 运行时或应用。

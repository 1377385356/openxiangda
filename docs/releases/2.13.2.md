# OpenXiangda 2.13.2：管理后台优先规范同步

将标准管理后台优先和 OpenDesign 页面归属规则同步到统一包、CLI 与 Skill 包，确保新应用开发遵循同一应用结构。

## 新增能力

- 统一包、CLI 和 Skill 包同步应用骨架与 OpenDesign 页面边界规范。

## 修复问题

- 防止用户端原型、单页 HTML 或 iframe 被误当作管理后台。

## 受影响用户

- 使用 OpenXiangda 2.0 创建应用和执行 AI 辅助开发的开发者。

## 升级步骤

- 升级 openxiangda、openxiangda-cli 和 openxiangda-skill-kit 到本版本。
- 刷新项目 Skill 后重新执行应用结构和入口验收。

## 已知限制

- 本版本更新规范和模板，不自动改造已有应用。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- platform: 本轮不增加平台后端接口或数据库迁移要求
- v1: 保持独立 legacy-v1 引擎

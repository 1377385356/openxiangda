# OpenXiangda 2.31.8：富文本图片与原通知投递恢复

支持具名动作的富文本托管图片，并公开按原消息查询、恢复失败投递的用户态接口。

## 新增能力

- NotificationService 增加 listMessages、listDeadLetters、replayDeadLetter，固定应用环境并保留平台管理权限。

## 修复问题

- managedFiles 作者配置与 Native 编译支持精确 text.rich 字段，避免借用其他图片字段授权。

## 受影响用户

- 使用具名动作编辑富文本或需要后台管理通知投递的 V2 应用。

## 升级步骤

- 升级工具链；富文本插图依赖对应平台编译支持，开发态已有记录上传需平台开发态附件 RLS 修复。
- 通知死信 messageId 过滤和来源关联需对应平台版本；管理员分别授予 read、content:read、delivery:retry 权限。

## 已知限制

- 投影阶段尚无消息时死信关联字段为空；已解决死信保持既有 not-found 响应，客户端应刷新状态。
- SDK 和平台源码验证不代替目标应用实际图片上传、通知投递及权限验收。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: 新增富文本声明和通知来源过滤需同步支持本次变更的平台；不扩大普通用户发送权限。
- v1: 独立 V1 引擎不受影响。

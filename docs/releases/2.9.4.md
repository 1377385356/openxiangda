# OpenXiangda 2.9.4：DingTalk OA 工作通知 SDK

应用通过平台托管的 Notification Hub 发送文本或 Markdown 钉钉 OA 工作通知，并查询投递结果。

## 新增能力

- Nest SDK 增加 sendDingTalkWorkNotice 和 getDingTalkWorkNoticeResult。
- 工作通知支持按 Native 用户、部门或全员发送，平台负责渠道凭据、Native 标识映射、幂等、投递和审计。

## 修复问题

无。

## 受影响用户

- 需要从 OpenXiangda 2.0 应用发送钉钉文本或 Markdown 工作通知的开发者。

## 升级步骤

- 平台先部署匹配的 Notification Hub 服务并确认 DingTalk OA 渠道和 Secret 引用可用。
- 将应用的 openxiangda 依赖升级到 2.9.4，更新锁文件并通过标准检查。
- 在测试环境验证用户、部门和全员目标的发送回执，再使用同一候选晋级生产。

## 已知限制

- 首版内容类型为 text 和 markdown；钉钉最终接收结果仍以平台投递记录和钉钉响应为准。
- 发布包、平台部署和真实业务角色验收分别验证；本版本不自动配置渠道 Secret。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v1, v2
- v1Policy: V1 引擎和已有应用不变。
- platformPolicy: 需要部署包含 Notification Hub DingTalk OA 工作通知接口的匹配平台组合，并配置已启用的 OA 渠道。
- releaseChannels: latest / stable-v2：V2 正式版；legacy-v1：V1 维护版；alpha：预发布。

# OpenXiangda 2.22.6：cli 分发模板与 2.22.5 工具链对齐

openxiangda-cli 分发模板的锁文件随 openxiangda 2.22.5 / openxiangda-nest 2.4.11 重新生成，使新建应用直接落到断言 TTL 双端一致的 SDK 组合。

## 新增能力

无。

## 修复问题

- 修复 cli 2.5.8 制品与本地模板内容不一致导致 release-immutability 门禁拒绝的问题：模板锁文件现随同发布单元递增（openxiangda-cli 2.5.9）。

## 受影响用户

- 通过 openxiangda create / cli 模板新建 2.x 应用的开发者。

## 升级步骤

- 无需手动操作；新模板自动携带 openxiangda-nest 2.4.11（应用侧断言 TTL 上限跟随平台配置）。

## 已知限制

- 模板锁文件对齐为随版次发布的机械变更；存量应用仍按各自锁文件升级，不受本版影响。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: 无平台服务依赖。
- v1: V1 工作区不受影响。

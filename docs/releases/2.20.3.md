# OpenXiangda 2.20.3：标准日期时间选择修复

修复指定时区的 PC 标准日期时间控件缺少小时和分钟列的问题，普通字段、生成表单、筛选与范围共用修复，不改变 UTC 存储和移动端协议。

## 新增能力

无。

## 修复问题

- 分钟精度显式显示时、分列，秒精度显式显示时、分、秒列。CLI 新应用模板同步钉扎修复后的根包。

## 受影响用户

- 使用 Field Kit 指定时区日期时间输入的 OpenXiangda 2.0 应用。

## 升级步骤

- 将应用精确依赖升级到 openxiangda 2.20.3，按锁文件安装并验证日期选择后发布预发布版本。

## 已知限制

- 服务端业务时间窗、权限、DST 不存在和重复墙上时间校验保持原约束。本修复不替代应用真实角色验收。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: 无需服务端或数据库迁移。
- v1: V1 工作区与维护引擎不受影响。

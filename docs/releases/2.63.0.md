# Workflow design, handling nodes and editable application templates

Publish the reviewed mainline workflow designer and handling capabilities, shared-record Save, structured parallel branches and guarded workflow source synchronisation. Add editable templates, resource reference read/update contexts and read-only AI command reconciliation. The platform must use the same public contracts 2.79.0 pure compiler as the SDK.

## 新增能力

- Canonical workflow designer definitions, target/variable catalogs, administration, proposals and instance adoption share the same pure validation rules.
- Independent handling and correction nodes support explicit completion actions, opinion requirements, shared-record Save, return policies, durable reminders, platform notifications and supervisor-chain assignments.
- Paired parallel/join nodes have bounded disjoint branches, branch-scoped position proofs and publication validation while retaining immutable task-entry authority.
- Workflow source export/import, read-only version registration plans and environment synchronisation use digest and target-head guards and preserve prepared version history.
- Editable application templates cover administration, PC, mobile and login frames, with shared resource-page controllers, source digests and composition validation.
- Resource reference filtering has an independent read intent; ordinary edits supply saved-record id/revision and actual edits for authoritative server-side merge.
- AI reconciliation binds a read-only GET/read operation to the original command receipt instead of replaying a business mutation.

## 修复问题

- Give the new workflow pure-rule APIs a fresh public contracts version so platforms need not privately add exports under an already published semver.
- Correct canvas branch selection, outline hierarchy and approval action presentation while retaining permissions, CAS, idempotency and unknown-result recovery.
- Export standard resource query, cascade and address helpers from shared contracts so browser and platform consumers use the same query semantics.

## 受影响用户

- OpenXiangda V2 platforms and applications using workflow design, independent handling, shared Save, reminders, notifications or instance adoption.
- V2 workspaces using editable template composition, resource reference fields or read-only AI result reconciliation.

## 升级步骤

- Deploy a platform matching the actual contracts 2.79.0 native validator first. Server contracts must come from the official published tarball with verified SRI.
- Upgrade the complete workspace distribution to public openxiangda 2.63.0, install the lockfile and refresh project documentation and MCP sessions.
- Preserve application, record, task, workflow-version and idempotency identities. Run normal check/deploy preflight against the actual platform capabilities and validator digest.
- Verify workflow design, shared Save, handling completion, return paths, notification recipients and reference reads/updates with real roles before environment promotion.

## 已知限制

- New reference contexts and workflow contracts require the matching platform to be deployed first; declaring a different digest does not establish compatibility.
- Template appearance and package regressions do not replace real-role, notification, instance-adoption and business-data acceptance.
- The separate event-receipt lease-ownership and worker-effect candidates are not included in this public release.

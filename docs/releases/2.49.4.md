# 统一入口校验 Native 事务

应用业务测试可以从统一根包读取共享事务校验器，验证实际生成的守卫而无需额外依赖底层实现包。

## 新增能力

- openxiangda/testing 导出 validateDataTransactionRequest 与 SCHEMA_VERSIONS，保留共享合同诊断。

## 修复问题

- 补齐统一依赖约束下业务事务测试缺少受支持校验入口的问题。

## 受影响用户

- 编写 Native 原子事务和 BusinessProcess 提交业务测试的 V2 应用开发者。

## 升级步骤

- 消费同源精确根包后从 openxiangda/testing 导入，不添加底层包依赖。
- 本轮仅导出本地密封测试分发，不执行 npm 发布。

## 已知限制

- 合同诊断不替代真实权限、数据库并发、业务运行和恢复验收。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- platform: Native 事务合同不变，稳定 1.x 不受影响

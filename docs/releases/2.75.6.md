# OpenXiangda 2.75.6：同域名独立租户的浏览器会话协调

平台显式按应用路径绑定独立租户时，SDK 使用平台提供的范围隔离跨标签页会话通知，并为共享接口续期传递应用路由上下文。未绑定应用沿用原有平台会话。

## 新增能力

无。

## 修复问题

- 隔离路径绑定租户的 BroadcastChannel 与 localStorage 退出、组织切换通知，避免新旧租户页面互相失效。
- 共享平台接口请求和续期携带应用路由提示；身份与租户校验继续由服务端完成。
- CLI 模板及官方 contracts 制品随同一源提交配对发布；编译器授权和业务语义未改变。

## 受影响用户

- 在同一域名不同应用路径部署独立租户的站点维护者及应用用户。

## 升级步骤

- 部署兼容 SDK 的应用前端并保留成功 TEST 运行；正式复用该不可变版本。
- 随后在配套平台显式配置精确 host、应用编码与租户编码绑定；不修改旧域名归属，不合并账号或目录。
- 分别验证新旧登录、续期、退出、跨标签页及真实钉钉回调；包发布不代表现场业务验收。

## 已知限制

- 路径隔离保留独立登录态，但不同路径仍属于同一浏览器 origin，并非跨来源脚本安全隔离。
- 旧 SDK 会忽略新增范围元数据；必须先更新相关前端再启用独立租户入口。
- 免登仍要求对应租户的真实钉钉配置与用户身份，不会继承其他租户账号。

## 关联 Issue

无。

## 兼容要求

- node: Node.js 24 or newer for maintained toolchain
- generation: OpenXiangda V2; unbound and V1 session coordination unchanged
- platform: 需要支持应用入口绑定、独立平台 Cookie 与 openxiangda-platform-session-scope 元数据的配套平台。平台消费同源 openxiangda-contracts 2.95.6 制品。
- releaseChannels: latest / stable-v2

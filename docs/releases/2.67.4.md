# 单角色源码往返修复与流程管理基础契约

修复 Source v2 混合流程普通单角色办理配置校验问题，包含已合入主线的按操作授权流程管理基础契约。不启用管理授权或条件画布功能，不部署生产。

## 新增能力

- 增加环境隔离的流程管理授权、设计器 published/draft 视图和原操作结果查询基础契约；配套服务端与 SDK 未就绪前不开放。

## 修复问题

- Source v2 普通单角色 handling 恢复为 roleCode，多角色仍按 roleCodes 并集校验；普通抄送节点保留原有角色/人数导出格式。

## 受影响用户

- 使用条件规则与普通节点混合流程导出的 V2 开发者。
- 维护流程管理授权协议的工具链与平台开发者。

## 升级步骤

- 按工作区工具链锁升级，不自动迁移 V1。
- 平台消费正式 contracts 制品并完成导出回归后再更新平台组合。

## 已知限制

- 条件审批 PC 编辑、公开能力门禁和真实业务验收仍须另行闭环。
- 流程管理 R1 仅基础契约，不是业务角色管理功能的完整交付。
- 不包含生产部署或业务数据修改。

## 关联 Issue

无。

## 兼容要求

- node: Node.js 24 or newer for the maintained toolchain
- generation: OpenXiangda V2; no automatic V1 migration
- sourceBundle: Existing v1 and v2 formats retained

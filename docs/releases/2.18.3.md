# OpenXiangda 2.18.3：xlsx 依赖镜像化，去除 SheetJS CDN 单点

openxiangda 包的 xlsx 依赖从 cdn.sheetjs.com 直链 tarball 迁移到本仓库 GitHub Release 的 vendor-mirror 镜像资产；字节与上游一致（sha256 相同）并继续由锁文件 integrity 钉住。

## 新增能力

无。

## 修复问题

- 消除 SheetJS 官方 CDN 单点：该直链曾在发布验证中造成 ECONNRESET 整轮报废；GitHub Release 资产端点对 CI runner 与一般网络更稳定。
- 依赖字节不变：镜像 tarball 与 cdn.sheetjs.com 原件 sha256 一致（8dc73fc3b00203e72d176e85b50938627c7b086e607c682e8d3c22c02bb99fe8），锁文件 integrity 保持内容可验证。

## 受影响用户

- 所有安装 openxiangda 2.18.x 的应用（安装链路不再依赖 cdn.sheetjs.com 的可用性）。

## 升级步骤

- 应用精确依赖升级到 openxiangda 2.18.3 后重新安装并运行 check。

## 已知限制

- 镜像资产托管在本仓库 GitHub Release（vendor-mirror tag），仓库可用性成为新的安装依赖面。

# OpenXiangda 2.25.1：精确十进制契约对齐

补齐可选精确十进制字段的公开 Schema 与共享 contracts 包版本，并声明 Native 十进制额度预留动作的受限契约。

## 新增能力

- Native 精确十进制额度预留动作提供有界声明和请求契约；编译器校验资源字段、状态及同资源动作的金额映射冲突。

## 修复问题

- 公开字段 Schema 中的 exactDecimal 与共享 contracts 包的字段清单、生成 Action 和资源 Schema 保持一致。

## 受影响用户

- 显式启用 exactDecimal 的 V2 Native 应用和准备使用额度预留动作的开发者；未启用这些能力的应用行为不变。

## 升级步骤

- 先发布并部署匹配的 contracts 包与平台服务端，再生成和发布使用 exactDecimal 的应用。
- 额度预留动作只有在目标平台完成对应运行时部署及真实业务验收后才能启用。

## 已知限制

- 本版工具链提供声明和请求契约，不单独证明额度预留动作在任何客户生产环境已经可用。
- npm 包发布、平台部署和应用真实角色验收分别记录。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: 需要部署支持精确十进制字段及相应动作契约的匹配平台服务端
- v1: 独立 V1 不受影响。

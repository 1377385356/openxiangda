# 流程实例撤回期限与业务终止授权

为标准流程实例增加可选的撤回时间限制和精确业务能力终止授权，应用编译器与平台共用策略校验。

## 新增能力

- 流程可声明 instanceCommands，以必填时间事实限制撤回，并以同应用的精确能力授权业务管理员终止。

## 修复问题

- 阻止未绑定时间事实、跨应用能力和未声明终止能力进入可发布应用包。

## 受影响用户

- 需要限制标准流程撤回时间或授权业务角色终止流程的 V2 应用开发者。

## 升级步骤

- 将应用 openxiangda 精确依赖升级为 2.3.0，更新锁文件并刷新技能与资料。
- 待目标平台部署匹配版本后执行正式检查、测试发布及真实角色验收。

## 已知限制

- 新策略只作用于声明该策略的新定义，不改写既有实例固定的定义。
- 撤回和终止的线上执行由平台版本提供；本工具包发布不代表平台已完成部署。
- 驳回意见校验与 Data API 事务时钟问题不在本次工具包修复范围。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v1, v2
- v1Policy: V1 引擎与应用契约不变。
- platformPolicy: 开发与部署需要匹配的共享校验器版本。使用新策略必须由平台提供 workflow.instance-cancellation-policy 1.0.0；平台预检会拒绝不支持该能力的版本。

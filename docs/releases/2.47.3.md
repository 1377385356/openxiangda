# 任务条件材料首次显示的空值修复

任务根字段及子表首次显示未填写的附件或图片时，使用标准空数组完成保存和私有草稿编码。

## 新增能力

无。

## 修复问题

- 任务附件和图片控件未填写时统一编码为空数组，避免条件字段首次显示后因null违反Native值合同。
- 根字段和owned子行共用编码规则，保留子行身份、只读和隐藏字段提交边界。

## 受影响用户

- 使用标准流程任务表单、条件附件或图片字段及任务私有草稿的OpenXiangda 2.0应用。

## 升级步骤

- 按精确版本升级SDK及同批CLI；首次条件激活还需要平台Server配套省略本次空材料写入。本批仅供本地验证，不执行npm发布。

## 已知限制

- 上传及非空材料引用仍按已经保存的页面条件校验，需要先保存使字段生效。
- 不调整源流程子表容量，不代表学校完整业务迁移验收。

## 关联 Issue

无。

## 兼容要求

- node: >=22.12.0
- platform: OpenXiangda 2.0；不改变1.x运行时

# OpenXiangda 2.8.0：审计信息读取权限

模型声明审计信息读取权限，统一保护记录元数据、查询和变更历史。

## 新增能力

- 模型及直接资源可声明 audit.read，使用现有能力和角色成员权限控制四个审计元数据字段与历史读取。
- 标准详情页随受权记录元数据显示变更历史入口，PC 和移动端保持一致。

## 修复问题

- 修复业务字段已经受限时，创建人和更新人仍可能通过系统元数据泄露的问题。

## 受影响用户

- 需要对忙碌、匿名化或受限业务投影隐藏操作人身份的应用开发者。

## 升级步骤

- 先部署支持 data.audit-read-access 的平台组合，再升级应用到 openxiangda 2.8.0。
- 在需要限制的模型声明 audit: { read: false }，或声明授予管理角色的能力数组，并执行真实角色验收。

## 已知限制

- 省略 audit 保留原有读取行为；应用可信后端和现有超级管理员权限保持原有语义。
- 受限应用启用后不可回退到忽略审计策略的后端；须保留兼容平台组合或先撤销该应用用户访问。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- platform: 声明审计读取规则需要 data.audit-read-access 1.0.0

# OpenXiangda 2.24.3：资源条件文本不变量

Native 资源可声明单选字段取指定值时，另一个文本字段必须包含非空白正文；平台在写入最终候选记录时统一校验。

## 新增能力

- 资源 invariants 新增有界 nonBlankTextWhenOption 表达式，只接受已声明的单选值和长短文本字段。

## 修复问题

无。

## 受影响用户

- 需要阻止标准管理页面或直接 Native CRUD 绕过表单校验的 V2 应用。

## 升级步骤

- 先升级安装匹配 contracts 包且已部署条件不变量校验的 Native 平台服务。
- 逐环境盘点并按业务审批修复既有违反条件的记录，再在应用资源模型声明新规则、重新检查和发布应用。

## 已知限制

- 规则只约束声明后的 Native 写入；历史记录不会被自动更改，应用读取与业务渲染仍须保持失败关闭。
- 规则不读取附件正文，不能用文件存在代替可审阅电子正文；npm 发布和客户平台发布分别验收。

- v1: 独立 V1 不受影响。

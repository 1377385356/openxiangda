# OpenXiangda 2.29.2：退役 Studio 专属工具链

移除已停止维护的 Studio 初始化、发现与绑定接口，保留普通应用创建、连接开发、源码托管和结构化命令输出。

## 新增能力

无。

## 修复问题

- CLI 不再接受 Studio Project/ProvisioningRun 初始化参数，能力发现不再输出 toolchain.studio。
- 通用 JSON/JSONL 事件和模板摘要绑定使用独立 CLI 契约，不再依赖已退役产品。

## 受影响用户

- 使用 OpenXiangda 2.0 工具链的开发者；仍调用 Studio 专属参数或导出的集成需要移除这些调用。

## 升级步骤

- 更新到 openxiangda@2.29.2 并更新项目锁文件；使用普通 create、dev 和发布流程。
- 移除 Studio 专属参数与导出。平台端退役部署须独立完成临时 Git 凭据撤权检查，不能仅凭 SDK 升级判定现场退役完成。

## 已知限制

- 已退役的 Studio 专属导出和参数不再兼容。
- 本次发行不包含新的平台 Agent 运行时，不自动部署平台或应用。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: 普通应用开发和共享源码托管契约保持；平台退役按独立部署前置条件执行。
- v1: 独立 V1 引擎和工作区不受影响。

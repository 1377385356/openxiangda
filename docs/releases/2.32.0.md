# OpenXiangda 2.32.0：自定义后台壳层与精确时间交互

提供正式后台壳层扩展，改进时间禁选、业务错误与内网开发诊断。

## 新增能力

- 应用可通过 ui.admin 提供完整后台壳层或顶栏、侧栏、页脚插槽，消费权限过滤后的导航与身份。
- 消息与待办导航可分别配置显示，资源深链接与移动端页面统一使用自定义壳层。

## 修复问题

- 日期时间控件按时区精确禁用小时、分钟、秒，保留输入校验和受控值。
- 业务拒绝的中文 message 与错误码、requestId 分离，避免页面丢失实际提示。
- 开发连接故障区分 DNS、TCP、TLS 与超时并提供安全恢复提示。

## 受影响用户

- 使用自定义管理后台、精确日期范围或校内网络开发的 V2 应用。

## 升级步骤

- 升级 openxiangda 至 2.32.0，重新安装依赖并构建应用。CLI 模板随同版本化。
- 按公开 ui.admin 契约接入壳层；路由、登录与授权继续由平台负责。
- 基础记录字段默认读取及受管下载文件名需要配套平台后端升级；仅升级 npm 不会更改服务端。

## 已知限制

- 自定义壳层接入和业务页面设计仍由应用负责，升级 SDK 不自动替换现有 UI。
- 网络诊断不自动改变 VPN、系统代理、证书或重试未知结果写请求。
- 前端时间禁选不能替代应用服务端业务时间守卫。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: 沿用现有认证、权限与路由协议；基础记录元数据的后端调整需对应站点发布。
- v1: V1 引擎与既有业务不受本次 SDK 改动影响。

# 限定职责选人的字段与流程合同

定义人员候选职责、记录范围和固定流程字段绑定，编译时拒绝来源漂移和范围绕过。此版本用于后续运行时接入，尚未开放该平台能力。

## 新增能力

- user.single/user.multiple 的 userCandidates 引用同包职责与可选范围，schema、Surface和纯编译器共同校验。
- form_field_users 的 candidateField 精确引用主体字段与事实投影，禁止重复来源配置、嵌套路径绕过和任务同时修改范围与选择。
- 使用该声明自动要求 data.user-candidates@1.0.0；未支持的平台必须拒绝部署。

## 修复问题

无。

## 受影响用户

- 需要按职责和已保存业务范围选择审批人的 V2 应用开发者及平台维护者。

## 升级步骤

- 本轮只固定本地合同包供平台接入，不执行 npm 发布或生产部署。
- 应用须等待 Native、Workflow、SDK及双端组件验证完成且平台广告能力后再采用声明。

## 已知限制

- 尚无公开候选接口或完整运行时约束；仅有编译检查不能证明选人或流程验收完成。
- 首版任务只支持主体候选字段，可写子表候选字段明确拒绝；新建不能提交非空的记录范围选人。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- platform: 目标须支持 data.user-candidates@1.0.0；1.x 不消费新合同

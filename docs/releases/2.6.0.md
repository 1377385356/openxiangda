# 统一应用时区与日期时间输入

应用可指定业务展示时区，标准字段、审批详情、待办、通知和审计时间统一显示，日期时间输入仍保存 UTC。

## 新增能力

- OpenXiangdaApplication 和 OpenXiangdaUiProvider 接受可选 timeZone；日期时间字段可覆盖时区并声明 min、max 和 minuteStep。

## 修复问题

- 修复设备时区不同导致日期时间编辑和公共详情、中心时间不一致的问题，拒绝夏令时不存在或重复的本地时间。

## 受影响用户

- 需要固定业务时区或限制日期时间输入的 V2 应用开发者。

## 升级步骤

- 将应用精确依赖升级至 openxiangda 2.6.0，更新锁文件并刷新技能资料。
- 在应用入口指定业务 timeZone，验证 PC 和移动端编辑、审批摘要与各中心显示。

## 已知限制

- 时区只影响呈现；服务端仍须独立验证业务时间窗口和授权。
- 手机指定时区的日期时间滚轮提供当前选择前后各 365 天并按限制收窄；夏令时重复时间需选择其他无歧义时间。
- 包发布、应用部署和实际业务验收分别验证。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v1, v2
- v1Policy: V1 引擎和已有应用不变。
- platformPolicy: 展示与输入能力，无新增服务端契约或数据库迁移。未配置时区和限制的应用保留设备本地行为。

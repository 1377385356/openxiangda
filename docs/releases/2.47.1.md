# OpenXiangda 2.47.1：子行材料控件与预览修复

修复子表多行控件重叠和富文本暂存后内图预览失效。

## 新增能力

无。

## 修复问题

- 子行表单显式采用纵向布局，附件、签名和富文本按真实内容撑开行高。
- 富文本水合只管理自己创建的预览URL，避免重用编辑器已经释放的临时URL。

## 受影响用户

- 使用子表材料、根或子行富文本图片和私有草稿的V2应用。

## 升级步骤

- 消费同批SDK与CLI后重新构建应用；现有记录、文件、草稿和固定任务定义无需转换。

# OpenXiangda 2.31.3：业务 Agent 结果卡片声明

应用任务可以声明已完成操作的只读结果卡片。编译器把展示字段限制在响应 Schema 的顶层标量属性，并将声明随应用版本发布。

## 新增能力

- backend.operations[].ai.agent.resultCard 支持标题和最多 8 个结果字段，并校验字段引用、类型及边界。
- 开发文档、速查表与 AI Skill 同步给出结果卡片示例和接入规则。

## 修复问题

无。

## 受影响用户

- 需要在平台助手会话中展示预约、报修等业务回执的 OpenXiangda 2.0 应用开发者。

## 升级步骤

- 升级 openxiangda 并更新锁文件；在业务操作的 responseSchema.properties 中声明可展示的标量字段，再可选配置 agent.resultCard。
- 在预发验证完整业务结果、字段缺失和刷新恢复；卡片展示需要配套平台服务端与前端版本。

## 已知限制

- 本版只定义已完成业务操作的只读结果卡片；待补信息表单、持久 Interaction 与应用自定义 React Host 尚未发布。
- 结果卡片不改变应用权限、业务执行或既有 MCP Facade 的确认协议。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: 结果卡片呈现需要配套平台 Agent 回执投影和会话前端。
- v1: 独立 V1 引擎和工作区不受影响。

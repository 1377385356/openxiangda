# 单人资料的条件唯一约束

Native 唯一键可以按平台用户的稳定身份和布尔启用条件约束有效资料，并由数据库处理并发冲突。

## 新增能力

- user.single 支持 exact-v1 唯一键；布尔字段支持 eq/ne 条件。
- 仅使用新增声明时要求 data.unique-keys 1.1.0，既有规则维持原能力要求。

## 修复问题

无。

## 受影响用户

- 需要每人仅一份有效资料、同时保留停用历史的 V2 应用开发者。

## 升级步骤

- 使用精确同源 SDK 和支持 data.unique-keys 1.1.0 的平台；通过普通模型声明安装规则。
- 历史有效资料重复时先按业务处理冲突，平台不会自动删除或停用记录。
- 本轮仅导出本地密封分发，不执行 npm 发布。

## 已知限制

- NULL 不参与布尔 eq/ne 条件；规则仍限 8 个，每个最多 4 字段和 4 条件。
- 已安装规则的删除仍需托管迁移，不通过普通旧版本激活移除。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- platform: 新增声明要求 data.unique-keys 1.1.0；稳定 1.x 与既有唯一键规则不变

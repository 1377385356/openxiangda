# OpenXiangda 2.46.2：重复字段的单选控件隔离

子表各行和同页面多个表单的单选状态保持独立。

## 新增能力

无。

## 修复问题

- 布尔和静态单选控件使用每个挂载实例独立的 HTML radio 分组，避免同名字段互相取消选中标记。

## 受影响用户

- 编辑子表或在同一页面使用多个表单的用户。

## 升级步骤

- 应用消费同批 SDK 和 CLI 后重建前端；服务端与数据合同无需变化。

## 已知限制

- 普通子表办理仍不包含子行附件、签名和富文本编辑；当前仅本地测试包。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: 沿现有任务子表能力，无新增开关或SQL。
- v1: 1.x 引擎保持独立。

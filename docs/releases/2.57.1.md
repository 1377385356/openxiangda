# 身份入口暂不可用时保留固定恢复期限

启用入口等待的平台可声明有界读取恢复预算，SDK继续恢复身份而不刷新原截止。

## 新增能力

无。

## 修复问题

- 修复入口429 unavailable无票据剩余时间时回落普通五分钟恢复的问题。
- 后续票据回执只能缩短截止；保留权限拒绝、失效、取消及写操作约束。

## 受影响用户

- 使用高并发入口等待与runtime身份读取的V2应用。

## 升级步骤

- 同时使用提供recoveryBudgetMs的Server及同源SDK；无该元数据时维持原五分钟恢复。
- 完整分发组合通过正式门禁后部署，保留原压测失败与期限。

## 已知限制

- 本批尚未完成公开npm发行和学校站点部署，源码测试不代表线上验收。
- 恢复预算只用于读取重试，不提供身份或队列位置，不延长Redis票据。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- platform: native-4、可选入口unavailable recoveryBudgetMs
- v1: V1不消费该恢复接口

# OpenXiangda 2.33.0：事务构建与部署前置诊断

在提交前定位事务组合错误，在构建前发现平台依赖故障。

## 新增能力

- openxiangda/nest 提供 createDataTransaction、diagnoseDataTransaction 和结构化构建错误。

## 修复问题

- 支持平台实时前置检查，发现内核、源码托管及镜像仓故障时停止后续构建。

## 受影响用户

- 编写后端事务或向私有平台部署应用的 V2 开发者。

## 升级步骤

- 升级 openxiangda 到 2.33.0 并重新安装依赖。
- 平台部署对应后端后自动启用前置诊断；事务构建器按文档显式接入。

## 已知限制

- 只读预检不保证后续写入或容量；原有部署和权限检查继续执行。
- 事务构建不自动合并重复写入，不替代服务端权限和并发判断。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: 前置检查按平台 capability 启用，旧站保持原部署流程。
- v1: V1 引擎与业务不变。

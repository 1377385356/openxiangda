# 对齐 AppSpec 正式发布资料预算

将正式发布生命周期的 AppSpec 当前资料文件上限与公开文档中的 512 文件预算对齐，支持完整记录的大型应用通过生产晋级预检。

## 新增能力

无。

## 修复问题

- 生产生命周期校验使用 512 个当前 AppSpec 非资产文件上限，不再以过期的 128 文件硬编码阻断大型应用。
- 保留单文件、总字节、资产和上下文预算，继续拒绝超预算、非法类型和符号链接输入。

## 受影响用户

- 当前 AppSpec 资料超过旧 128 文件上限、但仍符合 512 文件和字节预算的 OpenXiangda V2 应用。

## 升级步骤

- 使用本轮七包精确版本组合，并先执行 openxiangda check 与生产 promotion preflight。
- 继续完整记录应用目标、变更、设计、评审和验收，不要通过删除或隐藏活动资料规避生命周期校验。

## 已知限制

- 本次修正只扩大与文档一致的当前资料文件预算，不放宽单文件、总字节、原型资产、上下文或真实验收门禁。
- 本地检查通过不代表目标站点的生产身份、通知、密钥和业务验收已经完成。

## 关联 Issue

无。

- node: Node.js 24 or newer for maintained toolchain
- generation: OpenXiangda V2; V1 unchanged
- platform: Requires the matching OpenXiangda V2 configuration compiler and compatibility preflight

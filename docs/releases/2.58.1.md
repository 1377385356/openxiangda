# 同源交付记录流程历史及入口读取恢复

根包和模板消费新增 Nest 记录流程历史接口，并保留2.58.0的入口读取恢复与能力更新。

## 新增能力

- Nest 用户上下文支持业务记录流程历史读取，复用 Native/RLS、记录实例绑定、分页及修订校验。

## 修复问题

- 统一根包、CLI模板与Nest的精确发行版本，避免混用新增接口和旧归档。

## 受影响用户

- 使用 Nest 工作流记录历史或入口等待恢复的V2应用。

## 升级步骤

- 安装完整同源发行组合；入口预约与结果查询退避需要配套平台更新并重新校准请求图。

## 已知限制

- 2.58.0及本批尚未完成客户站点新候选容量验收；上一轮8000人仅7989人客户端30分钟内读回，最高完整通过仍5000人。
- 不改变流程办理权限，不自动重放业务写操作，不覆盖SSO集中登录容量。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- platform: 复用平台当前用户记录流程历史与V2入口能力
- v1: V1不消费该V2接口

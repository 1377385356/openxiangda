# OpenXiangda 2.9.0：声明标准列表导入导出入口

应用可按默认或命名视图配置标准列表的导入、导出任务，PC 与移动端使用相同声明。

## 新增能力

- crud[].list.actions 支持 import 与 export 布尔开关，直接资源声明同样支持。
- 关闭导入适用于原生与流程列表；关闭导出同时覆盖 PC 和移动列表。

## 修复问题

- 应用可通过公开配置移除首发范围之外的列表任务，无需修改共享组件或使用 CSS 隐藏。

## 受影响用户

- 使用标准 CRUD 默认或命名视图，需要控制导入导出入口的 V2 应用开发者。

## 升级步骤

- 平台采用 openxiangda-contracts 2.7.0，应用采用 openxiangda 2.9.0 后重新生成和检查。
- 在目标视图的 list.actions 中将不需要的入口设为 false，再部署测试候选并验证 PC/移动页面。

## 已知限制

- 省略开关保持既有行为；true 不授予权限，也不改变原生、流程或只读写入归属。
- 这是页面入口配置，Data API 和敏感字段仍按原有授权规则执行。
- 命名视图各自声明开关，不继承默认视图的任务选择；无需新增数据库迁移。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- platform: openxiangda-contracts 2.7.0

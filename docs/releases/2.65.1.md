# 条件审批人共享基础正式配对

将已合并的条件审批人纯规则基础纳入正式共享契约发布，保持既有流程语义和能力启用边界。

## 新增能力

- 有序首命中与必填默认来源的纯规则基础，按节点事实检查、叶子权限上限与有界严格求值。

## 修复问题

无。

## 受影响用户

- 平台维护者及使用 OpenXiangda V2 工作流契约的应用开发者。

## 升级步骤

- 统一更新 openxiangda、CLI 和 contracts 的配对版本；平台采用同一正式候选的七包归档与精确源码指针。

## 已知限制

- 仅发布共享基础，不开放流程注册 provider、编辑器或真实人员解析，不改变报销审批及财务提交策略。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- pnpm: 10.15.1

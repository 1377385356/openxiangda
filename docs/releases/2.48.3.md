# 审批节点的显式空人员策略

应用可按节点声明真实空审批人时阻塞或跳过，并在固定流程图和历史中展示实际跳过记录。

## 新增能力

- 审批 emptyPolicy 默认 block；显式 skip 仅接受受支持来源成功解析的真实零人结果，能力协商要求 workflow.approval-empty-policy@1.0.0。
- 冻结空人策略并显示已跳过；管理员仍只能修改代码允许的节点参数，不能更改空人策略或流程拓扑。

## 修复问题

- 新建标准申请中已展示的人员多选初始化为显式空数组；已有记录和接口漏传字段保持原语义。

## 受影响用户

- 需要区分无人跳过与最终必审阻塞的 V2 工作流应用。

## 升级步骤

- 同时升级服务端能力与精确 SDK/CLI 合同，重新构建应用；不需要数据库迁移。
- 本轮使用本地封装包进行合成验证，未执行 npm 发布。

## 已知限制

- skip 支持 fixed_users、input_users、form_field_users、app_role、app_role_in_scope；其他来源暂不支持。
- 缺失/null、非法账号、解析失败和退回补正不能自动跳过；完整源业务验收单独进行。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- platform: 要求 workflow.approval-empty-policy@1.0.0；1.x 不消费此能力

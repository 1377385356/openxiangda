# OpenXiangda 2.76.0：流程画布草稿编辑与拖动升级

统一已有及新增节点的草稿权限，提供明确投放槽、分支排序与节点独立退回设置，发布默认仅影响新申请。

## 新增能力

- 节点原位占位、浮动副本、合法投放槽及分组整体移动，保留缩放位置。
- 审批人、审批操作、更多设置三个Tab；退回目标在画布选取，默认分支固定最后。

## 修复问题

- 已有节点草稿编辑使用draft.edit，不再误依赖泛应用管理员或实时配置权限。
- 审批来源有界修改与运行覆盖按定义及绑定版本隔离，默认new_only。

## 受影响用户

- V2流程画布使用者及平台维护者。

## 升级步骤

- 升级配套平台后端并固定SDK2.76.0。
- 在TEST验证只读、草稿编辑、发布权限隔离和旧实例保持原版本后晋级。

## 已知限制

- 包测试与本地验收不证明客户站点已部署。
- 业务节点和取人规则仍来自各应用已发布定义，不自动恢复被删除节点。

## 关联 Issue

无。

- node: Node.js 24 or newer
- generation: V2
- platform: 需要配套草稿编辑、版本覆盖退休及组织事实校验后端；本地已验证，站点需单独部署。
- releaseChannels: npm.syedu.tech latest / stable-v2

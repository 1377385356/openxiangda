# OpenXiangda 2.46.1：未改动子表的完成校验

任务子表未修改时，提交校验读取当前已保存的行，保持差量提交语义。

## 新增能力

无。

## 修复问题

- 子表未出现在差量请求中时使用原页面行完成必填和结构校验，不再误判为空输入。

## 受影响用户

- 使用普通任务子表的办理人和应用开发者。

## 升级步骤

- 应用消费同批SDK和CLI后重建，服务端仍使用2.46.0对应的任务子表能力与正式SQL迁移。

## 已知限制

- 子行附件、图片、签名和富文本编辑继续后续；普通child并发新增尚无通用父集合锁。
- 仅本地测试包，尚未发布npm或迁移学校生产数据。

## 关联 Issue

无。

## 兼容要求

- node: >=24
- workspaceGenerations: v2
- platform: workflow.task-owned-subtables@1.0.0
- v1: 1.x 引擎保持独立。

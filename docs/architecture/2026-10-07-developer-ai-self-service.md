# 开发者 AI 的应用运行自助操作

状态：实施；单一主题为既有管理能力的 CLI/MCP 接入。

## 证据与能力归属

平台已提供环境事件状态、当前订阅恢复、加密环境凭据复制及通知诊断和默认渠道选择。
工具链只有部分旧管理客户端方法，缺少完整环境参数、原因、幂等身份和 AI 发现入口。
依赖管理页面或临时 HTTP 脚本会让应用 AI 无法自主完成已经授权的运维任务。
平台继续唯一拥有身份、授权、环境、事件事实、密文、消息及修订；Devkit 只拥有
固定操作目录、输入验证、受支持接口调用和中文指导。CLI 与 MCP 共用目录及服务。

## 不变量与合同

- 操作执行必须明确 test/production，映射到原 preproduction/production；绑定应用和站点
  只能来自工作区与现有开发者会话。拒绝额外 actor、租户、appCode、路径及环境字段。
- 目录提供各操作的输入 Schema、影响、权限、恢复条件。上下文、Skill、AGENTS 和 docs
  指向同一操作目录。MCP 传输同一 Schema，CLI 接受最多 32 KiB JSON 文件或标准输入。
- 密钥复制只传名称和两侧修订，不返回明文；来源与目标不同、每批最多 50 个唯一名称。
  服务器保持整批原子、同键同请求、来源/目标 CAS、密文版本和审计。
- 事件恢复限定原 deliveryId、原因和幂等键；useCurrentSubscription 必须显式传布尔值。
  不自动重发业务事务或更换幂等键，不提供全局清队列、扩大容量或停消费者的入口。
- 通知配置只接受 Secret 引用。默认选择核验规则和渠道修订；External HTTP 正式启用
  沿用服务器 confirmProduction 参数。健康测试不是实际老师收件验证。
- 恢复只处理指定通知死信；已送达/已恢复、任务时效和资格仍按消息 owner 判断。
  对结果未知、404 和修订冲突先读取原证据，不能自动改键或批量重放。

## 失败、并发、资源和安全

拒绝未知操作、额外字段、非整数修订、超限输入和跨环境复制。分页保留服务器 cursor/offset；
不会为了诊断无限遍历全量历史。认证、权限和服务器错误保留原 code/details；
CLI/MCP 返回可执行目录与指南，区分应用配置、权限委托、外部身份 owner 和基础设施故障。
不增加默认管理员授权、不持久化第二份运维状态或登录凭据。服务端仍复核所有资格。

## 影响和回滚

新增 V2 开发工具入口，不改变应用编译或业务运行合同，也不影响 V1。无数据库迁移。
旧平台缺少接口时明确拒绝并提示平台升级，不能降级到 SQL 或保护绕过。
回退工具代码只撤回入口，不删除已复制密文、修订、恢复投递和审计。
发行候选不得夹带尚未与目标平台配对的其他编译合同；按发布组合边界记录实际可用入口。

## 可证伪验收

实际 CLI/MCP 目录必须出现相同操作及输入；真实 MCP 协议和 CLI 解析证明明确环境、
禁止跨 owner 字段、分页与原幂等身份不变。HTTP 测试证明固定路由及原错误保留，
密钥返回中注入明文仍不进入工具输出。学校只读状态、诊断及无收件发送健康测试通过
官方新入口验收；过期修订复制必须 409 且目标不变。不得导入会员或重发历史老师通知。

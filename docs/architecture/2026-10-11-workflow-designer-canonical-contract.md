# Canonical workflow designer contract

Authorised scope: owner-approved Claude handoff dated 2026-10-11, session 5072bc85-80f0-43dd-91d6-df630b5d0c20. This is the P0 canonical authoring topic, with P1 execution maintained separately.

Contracts own the same WorkflowDefinition/WorkflowBinding consumed by developer authoring and the runtime. Semantic edits preserve IDs and connect a selected outgoing edge, never editor coordinates. Business steps, pages, field rules, validators, binding providers and opinion minima remain released capabilities. Insertion reuses a released template; conditions use typed known facts, bound depth, branch/node limits, no cycles and no orphan noncorrection nodes.

The platform owns shared drafts and immutable publication versions. Revision/head CAS plus exact request receipts govern writes. The request routing version may change; entered task people/mode/actions/page remain pinned. The pure migration classifier records holds, missing-node or missing-fact exceptions, and pending effects as deferrals. It does not execute migration or external effects.

Verification: selected-edge insertion/removal, original object immutability, type mismatch, malformed branch, cycles, missing current/return nodes, held/deferred cases and future-fact availability. The SDK is a consumer and the server is the only activation owner. No V1 behavior or package publication is part of this source change.

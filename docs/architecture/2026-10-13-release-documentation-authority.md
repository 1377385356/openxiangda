# 发布资料的权威入口

问题证据：应用 Skill、创建说明和模板 AGENTS 将工具维护者的主线冻结要求套给 TEST；已被替代的 CI 独占提案仍保留大段可执行步骤，容易在新会话被误当现行策略。平台 runbook 同时出现整 Deployment 恢复与字段归属恢复两种冲突说法。

所有者：平台 root 维护镜像/OSS/站点规则；工具仓维护 npm 规则；应用专题维护 TEST/生产规则。docs 单源生成 Skill references，入口和模板只保留稳定导航，不建立第二套发布 owner。

不变量/合同：记录与实际脚本一致；不改变权限、版本、测试、部署或主线门禁。应用 TEST 当前源码可部署；生产继续复用成功测试版本与原验收。npm 默认可信本机，原 tarball/receipt/integrity 恢复，CI 可选；平台更新继续迁移、CAS、drain 和 forward recovery。

失败/并发与界限：文档生成发现漂移或非法专题链接失败；本轮只更新明确文件，保留其他任务 runtime/新增专题。无外部消息、生产写入或新增凭据。SDK runtime 由应用助手主题唯一写者负责。

回退：资料主题可独立回退，无数据库或制品回滚；已发布历史字节不改写。过时执行策略移除，保留有日期的故障/试点证据及当前规则链接。

验证：正文生成及一致性、Skill 真安装摘要、文档构建与链接检查；后续正式候选仍验证包内真实资料。此验证不等于 npm 发布、站点更新或业务验收。

# 身份入口暂不可用时的有界读取恢复

r64 的原始身份请求证明：入口返回 429/CONCURRENCY_BOOTSTRAP_BUSY、state=unavailable、没有 remainingMs；21 个客户端在普通五分钟恢复期退出。Redis 回执不可用不代表原入口已过期，也不能据此生成新的票据剩余时间。

平台在已启用入口等待时，给 unavailable 响应额外提供 recoveryBudgetMs（配置的 waitMs，最大30分钟）。这是读取重试预算，不是票据 remainingMs、排队位置、身份或授权。SDK 从本次原身份读取开始固定截止；已有票据剩余时间只能缩短截止；后续预算、错误和重试不刷新截止。未启用、未携带有效预算、其他错误仍使用原五分钟规则。失效/满额和拒绝不重试；所有重试仅 current GET，不重放业务写操作。

平台 Redis 仍唯一决定真实票据生命周期、身份入场和原申请结果。读取恢复可继续等待，不能让已过期票据重新获得入场权。短轮询2–15秒加20%抖动、最多900次；取消/页面离开立即停止。

验收：持续 unavailable 超过五分钟后可读取真实身份；重复预算不延长期限；后续真实回执缩短；没有预算/畸形预算不扩展；过期/full/权限拒绝立即失败；悬挂读取和取消保留原行为。服务器与SDK分别提交，可独立回退；现役组合冻结，不将无关workflow契约升级带入站点。

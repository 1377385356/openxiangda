# 目标环境预检结果合并

能力合同不兼容不能继续解释配置；能力列表中缺少业务能力则仍可执行已协商的只读配置预检。过去先抛首个能力失败，应用补一项再发现下一项，且诊断缺少实际目标地址。现有 configuration-compatibility 仍为平台权威，不创建新端点或本地可用性权威。

CLI 在构建/镜像上传前聚合必需能力与已协商配置预检的缺项，携带实际客户端站点、应用、环境、平台版本和观测时间。保留原错误码与 requestId，unknown 不能视作通过；不重试写入、不自动修复 Secret。仅记录去除用户信息、查询和 fragment 的站点地址。协议不能协商时停止，不能探测猜测端点。

check 和 deploy 共用同一路径。预检成功不是后续发布成功，也不是持久授权：平台提交/激活仍重新检查。验证多能力+多配置缺失、协议不兼容零配置调用、目标去敏、零工作区构建副作用。可独立回滚工具，服务端旧错误兼容。

# 头像验收的受控图片响应

证据：冻结候选 974e5c25 的浏览器检查 177 通过、6 跳过；唯一失败发生在头像上传已完成且提示成功后，预期 img 不存在。夹具返回 https://cdn.example.test/avatar/new.png，却只模拟上传接口，没有提供 CDN 图片响应；Ant Design 在图片加载失败后撤掉 img。原上传 PNG 的 IDAT CRC 与压缩校验也无效。历史通过依赖在失败图片被撤掉前观察到 src，不能作为稳定验收。

Owner 为维护者浏览器夹具。提供固定有效的 1px PNG，对该夹具 URL 返回同一图片；继续验证当前用户的原上传/完成接口、一次回执、成功提示、最终 URL，并验证图片实际解码。不修改 Shell、头像回退、身份或文件服务；不增加真实外部请求、平台写入或应用数据。范围只覆盖此维护者用例，V1 和客户应用运行代码均无变化。

失败和并发仍由 Playwright 的独立 page/context 和既有单 worker 控制。资源限于几十字节、一个固定 URL，未扩大超时或放宽断言。先运行该用例核对实际解码，再按正式冻结制品门禁验证；维护者代码提交后新 HEAD 重新冻结一次，保留旧候选失败证据，不能手改通过回执。若七包字节不变，参考应用原精确锁仍可复用；若字节变化，由原入口重新准备锁。回滚限于夹具，并会恢复原网络依赖。

# Third-party card notification contracts

The platform owns enterprise authorization, directory conversion and delivery. Applications own immutable business recipients/content/targets. Event targetOrganizationPath requires trusted source lineage and class directory expansion stays in the source school. Rule owners must be read from Native organization_id, not application supplied replicas. Worker-effect may explicitly select this existing read-only metadata under the same bounded resource grant and org row policy; it cannot write it or select it without a grant. No migration or new identity store. Tests cover ungranted read/write rejection, source/target separation, directory and idempotency. Existing internal app channels and explicit recipient paths remain compatible.

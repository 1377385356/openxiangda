# 构建前运行配额预检

实施依据为平台服务器同日 runtime-capacity-plan ADR 与平台总方案 PLAT-004。Runtime 服务唯一计算容量，DeliveryRun 唯一识别原幂等运行。公开类型、能力发现、CLI/MCP 使用同一只读端点；不创建假版本、制品或凭据。

deploy 在检查脚本、镜像和上传前请求配额；dry-run 显示 required/available/shortages 与 observedAt，不预留资源。目标环境 ID 必须转发。旧平台缺少此能力时明确要求配套升级。checked=false 不等于充足；专用命名空间沿用未检查边界。预检后实际执行仍重新核验。

已密封候选可在昂贵步骤前只读验证并携带摘要及原幂等键；平台原运行匹配时无需新资源。检查后再次验证候选，候选变化即停止，避免用旧快照继续新构建。没有已验证候选摘要时不猜原运行；恢复使用 status/retry。仅 2.0 新交付受影响，1.x、业务权限和生产复用路径不变。公开契约、CLI、MCP 和资料同组 Changeset，可回退工具版本；不代替平台实例回滚。

验收：非法/缺失能力与异常响应拒绝、环境一致；真实 CLI 配额不足及 dry-run 不运行 check/test/build、Docker、密封或上传；服务端原运行、权限和配额计算有独立测试。维护替换另行实施，不自动停止旧实例。

源码验证：pnpm verify:affected 24/24 任务通过；独立 CLI 黑盒通过；新增容量响应、原运行和缺失能力测试 3/3 通过。尚未发包或部署，不宣称线上能力可用。

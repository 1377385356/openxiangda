## 证据与决定

现有产品设计检查只散列 Markdown，原型和 token 改动不会使确认失效；UI Provider 没有视觉输入；Skill/docs/CLI/MCP 已有同源分发。OpenDesign 07170f8d2213936b7862db04139d27e0af5437ed 的三个完整方法和九项 craft 可直接消费，另外若干目录是缺少完整内容的外部入口。采用精选原文、固定摘要、显式适配；不安装 daemon、额外模型或令牌服务。

## 所有者与稳定不变量

- design-capabilities/vendor 保存原文，lock.json 固定提交、内容与依赖；生成的设计专题供同版本 Skill、CLI、MCP 使用。
- AppSpec 是应用决定和实际确认的唯一记录。视觉设计包位于 appspec/design/system（manifest.json、DESIGN.md、tokens.css）；可运行原型放入 appspec/design/prototypes。visual 文档只索引，不重复数值 token。实现中的参数是派生物。
- 设计文档 assets 显式引用 appspec/design 内完整目录或文件。实际资源摘要进入设计与工作区摘要。引用目录内新增、修改、删除资源均影响基线。资源检查只读字节，不执行 HTML/JS；生产晋级读取测试提交中的资源。
- 用户拥有设计确认；结构检查不能证明审美、用户接受或业务正确。不伪造样例确认。
- 平台仍唯一拥有用户、角色、权限、字段值、路由和部署。Provider 只消费应用传入的主题与局部样式；沿用现有组件语义和 React 生命周期，不新增全局偏好状态。
- 已有 ResourceFormContent/ResourceFormDrawer 通过 Field Kit 提供给自定义任务页面；仅开放现有呈现边界和可选 title，不新增加载/保存/授权副本。样例观察到通用“编辑数据”标题与任务标题重复，使用 title 适配解决。
- 浏览器样例发现移动基础 CSS 在每个字段上重新声明 --adm-* 默认值，父级 MobileSurface 的自定义值无法继承。决定让这些默认声明读取可继承的 --oxa-mobile-* 输入并保留原值作 fallback。应用设计是唯一输入，未配置时视觉不变；不添加主题状态或媒体监听。通过嵌套字段和相邻应用的实际颜色验证隔离与回退。

## 影响与失败/并发

仅修改 V2 工具链，V1 与线上租户不变；应用需主动采用工具版本和设计。无参 Provider 保持原行为。资料修改不自动部署；当前受评设计不会被每日上游检查覆盖。

资源读取拒绝符号链接、越界、空目录与超预算，错误进入 AppSpec diagnostics。每次检查最多 128 个资源、8 MiB 总字节、单文件 2 MiB、16 层目录；同一调用复用摘要。未引用的应用源代码仍由原源码/交付摘要负责。原型自包含，外链只可作参考，不作为本地基线资源。冻结读取保留 Git 类型检查和预算。

上游检查使用 GitHub 固定提交 API 比较选中文件及新的候选目录；网络/依赖/许可失败保留旧资源并报告。候选更新在临时目录完成校验后由维护者评审差异、适配和样例；运行中的应用不下载 main。已有源码同步与单写者规则适用，不执行上游脚本。

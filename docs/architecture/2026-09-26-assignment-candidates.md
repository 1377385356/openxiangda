# 受业务动作约束的角色候选

合同复盘 B3：普通经办人需要候选人，但不能因此授予成员管理权。平台已提供 `directory.assignment-candidates` 1.0.0；SDK 在既有请求作用域目录服务添加可选方法，复用已验证动作的调用凭据与角色声明。

请求只允许角色、关键词、有界页长和游标；环境取模块绑定，禁止应用覆盖。响应封闭契约核验应用/环境/角色，游标不能跨上下文复用。候选只返回 value/label，身份状态由平台数据库时钟判断；提交仍必须在同一业务事务使用 role-member 守卫。

不改变现有目录、管理员 API 和默认 CRUD；不缓存权限、不自动重试、不遇错退回全员目录。旧平台明确返回不支持，应用要使用本能力才增加能力要求。SDK 回退只影响新增方法。

验收：未验证主体或未声明角色不发网络请求，正确透传短期动作凭据、请求关联 ID 和开发会话；越界/额外参数被拒绝，错环境和错角色响应被拒绝。平台真实数据库的成员有效期和并发撤销测试是服务端证据，SDK 测试不替代它。

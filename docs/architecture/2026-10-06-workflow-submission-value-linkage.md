# C25：标准发起表单的同步字段联动

状态：实施；依据为一网通办B04公共邮箱源V16，负责人变化复制管理专员，随后专员可独立修改。
现有标准表单只提供一次预填及隐藏/必填规则，不能表达可见字段联动；应用不能复制提交页。

唯一所有者仍是标准WorkflowSubmissionPage及Field Kit。新增可选valueLinkage(changed,values)
回调，接收当前可见、已匹配launch输入的canonical值，同步返回有限patch；通过同一codec
写回，标记联动字段已触碰，防止迟到预填覆盖。只在用户输入时调用；预填、草稿、读回、
隐藏规则及原提交恢复不触发，不递归调用。PC/手机复用ResourceFormContent输入事件。

回调的输入复制，不能修改原表单。返回值必须普通同步对象，字段只允许当前可见且可编辑
的launch输入；系统、只读和隐藏字段、Promise/数组均拒绝。失败保留输入并阻断新提交，
下一次成功输入可恢复；旧请求结果查询及已接受命令继续优先。回调不能授予数据权限、
读取可信身份或替代服务端校验，也不进行网络请求或持久化第二份表单状态。

没有异步竞态、事务和部署协议变更。1.x完全不受影响；未声明回调的V2应用行为保持。
回滚移除回调/新增API，已提交业务数据和回执不回退。公开API附文档和Changeset，
开发保持源码链接，不发布npm、不冻结其他包。批次退出时才统一冻结与激活。

可证伪验证：复制后独立修改、再次改负责人、清空、非法字段/Promise/抛错、日期codec
往返、原输入未被修改、联动值抵抗迟到预填；affected门禁。普通账号PC/手机及原结果恢复
放B04真实浏览器验收，辅助函数/类型测试不能替代页面证据。

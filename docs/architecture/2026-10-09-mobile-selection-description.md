# 移动选择字段的当前值描述

状态：实现决策已复核，沿用用户授权的平台问题直接修复；不涉及学校生产授权。

## 问题与所有者

真实本地任务的移动选人截图已显示正确的选中姓名，原命令和下一任务接收人也
已核对。MobileFieldTrigger的aria-label覆盖子元素文字，辅助技术只读出字段标题，
缺少当前值。问题属于V2 Field Kit的显示语义，不属于目录、审批人解析或权限。

## 决策与不变量

共享触发器以React useId产生组件内描述ID，aria-describedby引用其现有可见值
或空值提示。字段标题仍是可访问名称；选择、清空、禁用、关闭后焦点恢复、
值回传和弹层不变。不复制姓名，不新增目录请求、缓存、用户偏好或外部投递。
描述只包含已经显示的内容，不能带出未授权字段或隐藏的身份元数据。

## 影响与边界

只修改openxiangda V2的共享移动触发器，无服务端、数据协议、SQL或开关。
影响本来使用它的选择、日期等控件；稳定1.x不修改。每组件增加一个DOM ID
与引用，不增加数据量、请求或并发状态。React管理多组件和重渲染的ID稳定性，
不拼接真实用户标识。撤回该组件改动即可回退，不影响任何保存值、任务或审计。

## 可证伪验证

检查组件真实DOM中title名称保留，当前值通过描述引用可读取；选择变化和清空
后描述跟随既有值，多个字段引用各自的唯一元素。现有移动字段相关检查及
verify:affected按改动范围执行；浏览器核验来源和未验事项另行记录。
不把辅助技术描述缺失当作视觉姓名丢失，也不将修复计为学校业务路径通过。

# 应用管理导入：共享字段解析契约

2026-09-06；主题：管理导入的字段映射、部分更新解析和有界工作簿读取。

证据：现有 `parseResourceImportFile/Matrix` 只支持精确表头匹配、100 行新增及全部必填校验。管理后台需要保留标准字段格式，增加表头映射和更新匹配；不应复制第二套日期、选项、人员或引用解析器。

责任：`openxiangda/field-kit` 负责读取工作簿、映射和本地类型提示；平台 Native Data 负责授权、唯一性、真实记录匹配、修订、提交与事件。浏览器解析成功不代表获准写入。

新增只读 `readResourceImportWorkbook`，返回首工作表矩阵及表头。文件不超过 5 MiB、5000 数据行、256 列。原文件导入函数继续默认 100 行；`parseResourceImportMatrix` 可明确选择上限、列映射、必填检查范围及空单元格行为。跳过列不得写入，重复映射与非法字段报错，保留文件原始行号。更新默认跳过空单元格，显式清空才生成 null；创建记录必填和存储约束仍在服务器检查。

管理任务在服务器保存预览后确定的操作与记录修订；按原子行／聚合单元保存 Native 回执和检查点。新包不会创建后台身份、直接 CRUD、任务数据库或修改普通用户的默认导入行为。公开包添加 Changeset，由确定性发布流程选择版本。

可证伪验证：非标准表头映射、跳过列、重复／未知映射、部分更新、空值策略、5000 行边界、稀疏行的原始行号；原有标准解析和导入模板回归。仅新增参数与解析能力可独立回退，已经执行的数据任务不因包回退撤销。

浏览器验收补充：SheetJS 直接读取无 BOM 的 UTF-8 CSV ArrayBuffer 时会按单字节编码解释，中文内容出现乱码。CSV 先用严格 UTF-8 解码；有 UTF-16 BOM 时按声明解码；无法解码则提示另存 UTF-8 CSV 或 XLSX，禁止把替代字符或猜测编码静默写入原始数据。CSV 原始文本交给共享字段解析器处理，保留前导零、日期和公式样文本。二进制 XLS/XLSX 路径不变。

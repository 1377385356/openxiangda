# 标准列表与智能体共用查询语义

日期：2026-10-12。状态：实施决策已明确，验收待执行。

Claude 设计 09 第 5 节、10 第 5 节要求将标准列表的纯查询构造迁入共享契约。现有实现位于 openxiangda 浏览器组件目录；后端智能体若复制它，会产生第二套地址、级联、多选、区间与引用字段查询语义。

能力所有者是 openxiangda-contracts。将 resource-query 与依赖的纯 cascade/address 值函数迁到该包；浏览器原路径保留无逻辑的重导出。root、browser 与 native-compiler（平台 CommonJS）消费同一源。

稳定不变量：查询树、引用 value、区间边界、地址最深编码、级联叶子、空值和标准列表陈旧状态处理完全保持。共享函数只构造声明查询，不拥有身份、授权、数据库或新状态。智能体后续仍须验证视图允许字段，不能用此函数扩大查询权限。

影响契约：共享纯函数新增公开出口；现有浏览器导入保持。无网络、写入、并发或外部副作用。无新依赖；浏览器出口不得引入 Node 内置模块。回退此提交即可恢复原位置；不影响存储数据、稳定 1.x 或未消费新版本的应用。

可证伪验收：现有 resource-query/cascade/address 测试仍通过；浏览器与 CommonJS 原生编译出口构造相同查询；pnpm verify:affected 校验受影响构建、边界和包测试。无 npm 发布或平台部署。

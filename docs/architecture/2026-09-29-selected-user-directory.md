# 具名业务动作解析所选组织人员

## 问题与归属
管理员业务代办、积分调整与身份订正需要所选 userId 的真实姓名、工号和部门。现有 Nest Directory 只支持当前发起人，迫使应用维护第二份人员表。身份仍由平台目录独占。

## 决策与边界
增加可选 `platformAccess.directory.mode: selected-user` 和 `BusinessDirectoryService.selectedUser(userId)`；一次仅取一个确定人员，不接受姓名、工号、租户、角色或环境作为输入。调用者必须通过具名动作能力检查，并同时具备既有目录读取权。目标必须属于同一租户、处于有效期且可选；复用既有目录选择器作用域。只返回声明的四类字段与摘要、数据库读取时间。

旧 current-initiator 语义不变，V1 不受影响。无声明、非目录可读调用者、跨租户/无效用户、伪造个人字段一律拒绝。网络/权限失败不回退应用人员缓存。

## 失败、并发、资源与回滚
仅只读单用户；字段白名单、255字符ID、无批量遍历。读取返回时刻快照而非将来授权保证；业务动作继续独立检验权限与不变量。删除新声明/回退应用即可停用，平台API为增量、不需数据库迁移。

## 验证
编译器两模式/非法模式；SDK固定站点环境、拒绝额外输入、验证回包用户与schema；平台动作声明拒绝、目录权拒绝、无效目标拒绝、精确身份字段与无额外字段。站点部署和应用实测另由交付执行，不把源码测试当线上结果。

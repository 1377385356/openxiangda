# 流程详情读取失败的用户文案

状态：实施；本地真实身份迁移测试发现，浏览器拒绝路径待复验。

## 问题与能力所有者

在本地测试环境以不相关普通账号打开他人的流程实例，服务端正确拒绝，标准
详情页面却把 `WORKFLOW_V2_INSTANCE_FORBIDDEN` 原样展示给用户。任务不存在或
不可读取也使用同一错误展示函数。平台 SDK 的标准流程页面负责解释这些已知
读取错误；服务端继续唯一决定授权、存在性与身份。

## 不变量及契约影响

只增加四个既有错误码的中文解释：实例/任务的 FORBIDDEN 与 NOT_FOUND。
不修改 HTTP 状态、错误码、服务端授权、路由、返回资料、重试策略或 API 类型。
拒绝文案不披露他人姓名、申请内容或存在性细节；未知业务错误沿用原有解释。
同一标准组件的 PC 和手机路径一起生效。V1 引擎不使用此组件。

## 失败、并发与资源边界

展示仅来自当前读取失败；身份切换时仍由已有 detailKey 生命周期隔离状态。
增加固定常量映射，不增加网络调用、后台状态、缓存、自动恢复或副作用。
不可读取实例提示联系管理员确认权限；不可读取任务提示返回待办核对。

## 回滚及验证

独立回退文案提交即可，不回退人员导入、权限或原流程。复用已有 outsider
账号及已完成测试实例，在浏览器确认拒绝仍有效且无原始错误码；再恢复管理员。

# 日期时间控件的时分秒禁选

状态：实施中。已有 DateTimeConstraints 具有精确 min/max 与时区协议，但 PC ZonedDateTimeField 只传 minDate/maxDate，时分秒列仍可选择越界值；提交后才提示错误。

Field Kit 拥有规范瞬时值、IANA 时区转换和选择辅助。补充 disabledTime，对日期对应时区内的小时、分钟、秒分别判断可用范围；保留原 emit 的精确校验，不把 UI 禁用当服务端授权。分钟步长只允许对齐整分钟，秒边界按可表示的整秒收敛；不存在或歧义墙上时间继续拒绝，不猜测 DST 偏移。

选择列只计算当前天，每小时按需查找合法分钟并缓存，不枚举年份或无界生成候选。约束变化不自动写回 value，不覆盖其它表单字段；原已保存历史值保持展示。无新网络、权限或数据库写入，V1 不受影响。移除新增 disabledTime 可独立回退到原输入校验。

验收：同日小时/分钟/秒上下界、当前分钟中的秒、跨日、分钟步长、Shanghai/UTC/夏令时切换；PC 单值/范围/筛选及生成字段的真实浏览器禁用列与手输校验。测试数据均为固定时间，不依赖当前时钟。

# 新建工作区安装诊断

状态：实施。证据：2026-09-26 受影响验证 23/24 通过，新建工作区的真实依赖安装失败只返回 WORKSPACE_INSTALL_FAILED，丢失已捕获的包管理器错误；此前已修复的可选后端分类未覆盖 create。

CLI 拥有进程边界，devkit 统一拥有安全分类。create 复用固定错误码分类，保持原顶层错误码及重试协议；不返回原始 stdout/stderr、URL、路径或凭据。不根据未知退出原因认定网络问题。安装最多 180 秒，捕获输出最多 4 MiB，保留生成工作区用于原操作恢复。分类不引入新依赖、网络请求或业务写入，不影响 V1 路由。回滚可独立退回 CLI/devkit 版本。

验证：真实子进程输出含模拟 registry 凭据和固定错误码时，公开错误只有允许的分类；调用方看到原错误码；CLI 全链路黑盒及受影响检查继续验证实际安装。

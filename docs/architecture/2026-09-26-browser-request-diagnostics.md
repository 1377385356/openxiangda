# 浏览器请求诊断的完整传递

状态：实施。合同协同中 API 错误仅有页面文案，普通请求、文件导出、登录刷新、权限投影重试的 requestId 处理各不相同；最后一次只读重试还会丢掉已有 requestId，迫使平台上服务器猜请求。

平台中间件继续拥有服务端 requestId，SDK 从合法响应头优先读取，信封仅作兼容回退。浏览器统一错误对象携带请求方法、去除 query/fragment 的站内路径、观测时间、应用/环境，以及可复制的固定结构诊断。ID 仅接受最多 128 字符的标识符；诊断不包含请求正文、Cookie、token、响应 data 或自由文本 message。不生成第二套身份或后台日志权威。

网络失败保持结果未知，写操作不增加自动重试；取消保留 AbortError。既有登录刷新协议不变。权限只读重试耗尽保留最后响应诊断；文件导出复用同一错误类型。应用可通过公开 react 入口取得安全诊断，不再解析 Error.message。局部请求失败不转换成全局应用不可用。该变更只影响 V2 SDK，可单独回退。

验证请求头/信封优先级、非法标识符及敏感 query 去除、导出失败、4 次只读重试最终 requestId、网络写失败仅调用一次、取消，以及公开导出。真实现场日志查阅仍由现有授权支持通道负责；本功能不将请求未响应推断为未提交。

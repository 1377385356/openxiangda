# 固定公开单选过滤的一致性

问题：学校仪器目录 external_open_flag、公开统计 stat_period/open_enabled、轮播 enabled 均为 option.single；应用及 Native 两个编译器拒绝固定 eq 条件，但平台匿名服务 publicFilterWhere 已按 JSON value 实现相同条件。这阻断安全迁移，不能取消服务端过滤或在浏览器隐藏关闭记录。

所有者：公开读取合同与编译器。仅扩展固定单选 eq 的声明检查，保留字段白名单、每策略16条件上限、不重复及只读 policy。单选值仅字符串/null，拒绝对象、数组、布尔和数值；多选、文件、人员和任意引用仍不接受。平台继续读取当前不可变策略，客户端不能覆盖条件。

接口没有新参数；授权范围仍由应用发布白名单和固定条件决定。SDK与平台 Native compiler 必须配对发布，不靠改 node_modules 运行。运行时没有新增写入、定时任务或跨租户读取。未知部署沿原receipt恢复；可回退上一SDK/平台版本且不迁移数据。回归必须穿过应用声明及Native编译，保留复杂字段拒绝，学校实测关闭记录/文件不可公开读取。包测试不等于学校验收。

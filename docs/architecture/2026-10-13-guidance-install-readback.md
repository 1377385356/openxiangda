# 指南安装与读回

状态：实施；整链路方案 A1。权威正文继续由 `docs/` 经 `sync-developer-guidance` 生成 Skill references；Connected Dev 使用独立开发版本，不切换 TEST 发布 Head。

问题证据：当前安装仅复制资料并返回目录，无法证明实际启用的内容与当前包相同；复制失败分支还可能删除尚未备份的原 Skill。源文件、已打包文件和安装文件需要同一摘要证明。

所有者：skill-kit 拥有安装事务和内容校验；devkit 拥有文档主题；CLI 只投影安装结果。保留现有单一正文源，不新增指南状态库。

不变量和合同：安装成功必须读回与安装前源内容相同的目录摘要，输出真实来源路径、目标路径、SDK 版本、摘要及观察时间。旧安装在校验失败时恢复；用户的其他 Skill 不修改。扩展安装结果为附加字段，V1 分发不受影响。

失败与并发：目标目录安装使用独占锁；同目标并发立即报告 busy，不按锁年龄抢占。先校验 staging，再替换，读回目标后才移除备份。锁由取得者释放。失败未产生新目录时不得删除旧目录。

资源与安全：目录摘要拒绝符号链接及非普通文件，最多 10,000 项、32 MiB；不读取远端或凭据，不改变应用/平台运行态。

回退：回退安装器及新增输出字段；已安装正文仍可由原安装流程刷新。

可证伪验证：源/安装摘要一致；不同内容摘要不同；复制或读回失败恢复旧 Skill；并发锁拒绝；实际指南生成器 check 通过。正式候选仍须使用真实 tarball 门禁验证安装路径。

# 应用范围的原操作诊断入口

状态：实施。已有安全 requestId 定位信息和平台四类只读查询，但开发者仍需人工
拼接接口。补齐 devkit 客户端和现有 logs 命令，不新增日志服务或业务事实副本。

平台继续拥有身份、app 管理权限、租户/环境、持久回执与查询预算。SDK 使用工作区
已有开发者会话，只查询当前应用及明确环境；Nest 应用凭据不能调用管理诊断。
不接收任意 URL、tenantId、其他人的凭据或原始 SQL，不使用平台数据库连接。

logs 的默认最近部署行为保留。四种定位器互斥；requestId 使用显式时间窗口，
CLI 未指定时显示实际使用的最近一小时。原命令/部署/文件 ID 不带时间过滤。
SDK 在请求前核能力和形状，响应核对应用、环境、定位器和窗口后只返回已知元数据。
新的可选响应字段被丢弃，不让无关附加字段阻断旧 SDK；错误范围或主协议不能接受。
输出固定上限，不携带数据正文、文件名、原始日志、令牌或原始数据库错误。

未找到、暂时不可查询和已观测是不同结果。都不能把未知写入变成未执行，不生成
新幂等键，不自动重放、重试或关闭问题。CLI 在结果中同时保留站点、环境和观测时间。
精确定位本身不证明审批完成、文件有权下载或业务验收通过。

回退只撤下新客户端入口，旧 logs 与工作区不变。验证覆盖四类 GET、权限/缺能力、
跨应用/环境/定位器伪回执、窗口边界、脱敏投影、未知状态无重试，以及 CLI 参数与
默认部署分支。实际站点读回与包发行分别记录。

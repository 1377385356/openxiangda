# 标准工作中心视图深链

日期：2026-09-24
状态：实施候选（PL-32）

## 问题与能力所有者

合同管理 Head 133 的真实经办人从“查看我的申请”进入标准 `/work-center`，页面固定从 `pending` 加载，显示“待我审批 0”，而“我创建的”有 7 条。标准工作中心的初始视图属于 OpenXiangda 浏览器 SDK，任务列表与授权仍由平台 Workflow API 拥有，应用只负责提供入口 URL。

## 契约与不变量

- `/work-center` 和 `/m/work-center` 接受同一个 `view` 查询参数，只有 `created`、`pending`、`handled`、`cc` 四值有效；缺省或任何未知值按 `pending` 读取。
- 标签切换将所选白名单值写回 URL，使浏览器前进、后退和分享链接都与当前视图一致；保留其余查询参数，不将未知视图值传给服务端。
- 只改变客户端初始选择和请求参数。Workflow API 继续按当前用户角色并集、当前环境和既有权限决定可见记录。URL 不能授予记录访问权。
- PC 与移动使用同一组件。既有无参数入口保持 `pending`。稳定 1.x 应用不受影响。

## 失败、资源与回滚

非法、重复或超长参数不参与数据查询，只回退到 `pending`；不需要额外请求、存储或状态副本。组件原有加载、错误和分页行为保持。回滚仅需撤回该 SDK 包版本并将应用链接还原为无参数入口；服务端与数据无需迁移。

## 可证伪验收

PC 和移动分别验证 `created`、`cc` 深链第一条列表请求及选中标签；未知值回退 `pending`。既有无参数入口与手动切换四标签仍可用，后者 URL 与列表参数一致。具名经办人预发验收核对“我创建的”真实数量及记录，越权用户不能因 URL 得到额外记录。

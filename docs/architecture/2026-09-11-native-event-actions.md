# 平台原生数据事件动作

已获用户授权，属于写入路径精简重构。现有自动化只复制平台数据时，绕应用 HTTP 会产生接收领取、事务回执和投递结算等多次提交。共享编译器生成不可变 native-data v1 计划，平台 Native 内核执行，动作效果和投递结算同事务提交。

首版限定已声明的数据事件、明确源资源、create/update/delete 目标、常量或事件字段映射。最多 16 个操作、每个 32 字段、64 KiB；不接受脚本、SQL 或 HTTP。编译器自动收集捕获字段、目标资源摘要；运行时不能读取新版本重新解释旧事件。新能力码阻止旧平台接受；旧 HTTP 订阅契约和摘要不变。

权限、租户、环境、字段约束由原 Native 内核拥有。发布计划是内部权限来源，RLS 绑定确切 delivery/spec/digest。重复和人工重放使用原 delivery 效果标记；失败回滚后退避重试。无应用后端的标准 Native 自动化可独立运行，应用自定义代码仍隔离执行。

回退先停用并排空 native-data 动作，保留不可变执行计划与历史，不能让旧镜像把动作误投 HTTP。验证共享编译器一致性、非法绑定拒绝、RLS、原子回滚与重复执行以及真实场景完整对账。

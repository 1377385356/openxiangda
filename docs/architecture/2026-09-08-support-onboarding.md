# 支持协作接入

状态：按 2026-09-08 已批准的内部 AI 协作设计实施。

- 问题证据：统一入口仅安装应用技能，没有可执行的 DWS 安装、授权或支持群状态检查；仅声明技能依赖不会安装 DWS。稳定 DWS 1.0.61 的官方 multi bundle 包含跨技能引用，shared/chat/event 子集不能保证 misc/profile 等引用完整。
- 能力所有者：统一分发层负责接入编排及自己的协作说明；DWS 官方程序负责安装其完整技能、OAuth、账号和钉钉访问；平台继续拥有应用身份、权限、环境和源码托管。V1/V2 引擎不引入另一代运行时。
- 不变量：公开包只包含通道配置 URL，不包含实际组织、群或邀请地址。配置链接原样交给操作系统打开，用户在钉钉完成加入；不实现邀请兑换或管理员加成员。钉钉决定真实群访问结果，链接和组织 ID 不能证明群限制。
- 身份：使用已保存的精确 corpId:userId，或目标组织唯一 isOrgCurrent 账号；不选数组首项、显示姓名或最近账号。每个业务调用显式传同一 profile；不切换 DWS 或平台默认账号。只保存本地接入指针和安装回执，不复制 Token。
- 受影响契约：新增分发命令 support status/bootstrap/login/join；成功创建、V1 workspace init/bootstrap 和技能安装触发有界 bootstrap。OAuth 和打开群由对应显式命令执行。接入失败或等待用户操作不改变应用创建成功结果；补充进度写 stderr，保留引擎 JSON stdout。
- 失败和并发：通道最多 16 KiB、请求 10 秒，子命令输出最多 1 MiB 且有超时；安装和本地回执使用单写锁与原子替换。认证不可用、目标不符、群查询失败保留独立状态，不当作已入群或自动发送消息。--skip-support 可用于离线/CI 初始化；后续 support bootstrap 恢复。
- 访问证据：稳定 member-list 只返回 profile 范围的 openDingtalkId，而 auth status 返回组织 userId；不按姓名拼接身份。成功读取指定群只证明该账号能访问群；独立成员身份和组织限制没有验证时明确记录，不能额外承诺。
- 资源与权限：复用可用稳定 DWS；缺失时安装审核过的官方 1.0.61，全量 setup --mode multi。保留官方备份和 Runtime gate。首次授权由用户完成。支持技能不授予发送消息或高影响操作的新权限；已授权案例中根据范围持续协作。
- 回滚边界：本提交可独立回退；不会改业务数据、平台环境、源码仓库绑定或 V1 包。DWS 卸载、OAuth 撤销由用户在其正式工具中单独管理。
- 可证伪验收：替身进程/网络覆盖缺失安装、复用、全量技能、精确 profile、错误组织、部分结果、原样打开链接、待加入状态、网络失败、超时、锁冲突、JSON 分流、创建结果及两代引擎隔离。真实两个账号往返与生产支持服务验收另行记录，不用 mock 结果宣称通过。

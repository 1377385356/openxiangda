# 后端依赖安装故障可诊断

真实 CLI 黑盒安装 Nest 依赖失败，初始化器吞掉子进程状态，应用只知道检查网络；同一现象可能是安装器不存在、超时、认证、包版本或磁盘问题。

保持 pnpm 安装、180 秒预算、源码不覆盖和现有重试回执。失败只提取允许列表中的进程/包管理器代码和退出状态，输出确定的原因类别与下一步；不输出原始 stdout/stderr、路径、仓库 URL、token 或调用栈。分类不是安装成功凭据，任何失败均保留待安装回执。

黑盒测试仍执行真实安装；测试替身只在失败时透出阶段和允许列表错误代码，去除忽略所有错误信息的盲区。普通应用不新增日志数据库；未启用后端不受影响。

用确定性的分类测试和真实首次安装验证。故障恢复复用源码；权限/版本类失败不能被描述成无条件网络重试。回退只恢复旧提示，不改应用数据。

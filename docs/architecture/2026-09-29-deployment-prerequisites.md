# 构建前检查实际部署依赖

现场 enabled 配置与实际托管令牌、仓库账号和镜像服务不一致。平台唯一拥有上游凭据及内核状态，CLI 不持有这些配置。

平台广告 application.deployment-prerequisites 1.0.0 时，deploy 在本地检查脚本/镜像构建之前只读查询应用级报告。报告绑定 appCode、backend 与观察时间，包含 kernel/source/registry 三项，每项为 ready/failed/skipped。失败和不完整响应都停止构建；不触发自动修复或任何业务写入。前端应用可跳过镜像仓。

旧平台无 feature 时沿用原能力与配置预检。原有容量、权限和上传验收保留；诊断成功不证明写入、持续可用性或剩余容量。错误仅包含固定代码、中文指引及时间，不回传上游正文或凭据。

独立可回退，无数据库变更、不影响 V1。验收含错应用绑定、缺项、矛盾 ready 标记、required 能力被 skipped 和上游失败；服务端另验无权限零上游请求及凭据脱敏。

# 固定流程的代码逻辑说明

状态：源码实现与定向验证通过，待本地应用整批冻结消费。主题 C59。

## 问题与证据

安保五流程源码批次中，携物出门流程已有 `readability.logic` 的提交前身份判断说明。
`projectWorkflowGraph` 原样提供 `graph.logic`，共享 `WorkflowDiagram` 没有展示；
应用节点详情只查匹配 `nodeId` 的说明，未绑定节点的提交前逻辑不可见。
需求来自用户已确认的固定拓扑图：管理员应理解计算依据，代码与连接不开放修改。

## 所有者与不变量

共享根包 `openxiangda` 负责只读展示，契约和平台继续拥有定义、授权与运行事实。
不修改投影、定义摘要、节点/连线、条件、审批配置、办理操作和执行引擎。
说明不是可执行节点，也不是代码执行成功证据；不加载业务源码，不请求新接口。
只显示本定义已声明的文字、输入/输出及可选来源，不推断缺失输出。

## 设计与影响

复用现有工具栏、Ant Design 和页面视觉。PC/手机均增加默认折叠的说明区域，
按提交前、进入节点前、结束后分组；节点说明可以定位真实节点，实际路径过滤中
不存在的节点禁用定位。区域高度至多320px/38dvh，长文本和摘要可换行滚动；
原生 details/summary 提供键盘展开与关闭。无逻辑声明时不出现空区域。
定义图、实例固定版本、节点列表与加载失败的列表降级共用同一份声明。

## 失败、并发、资源与安全

只读本地渲染不产生写入、额外网络、授权状态或事务；当前实例实际路径过滤
不隐藏定义说明，也不将说明着色为已执行。文本由 React 转义，无HTML/代码求值。
投影既有最大节点与说明数量预算保持。不影响1.x及未使用流程图的应用。

## 回滚与可证伪验收

独立提交可回退根包组件与样式。运行 `pnpm verify:affected`；真实携物定义图
检查身份说明可展开、无输出声明不编造、直角线与原节点数量保持，手机无横向
溢出并保留节点列表。其他批次定义/实际实例图验证共享说明及无说明降级。
源码、冻结制品和学校完整等价分别记录，不用此显示证明代码运行。

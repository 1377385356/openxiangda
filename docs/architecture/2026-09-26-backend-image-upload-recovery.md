# 后端镜像上传失败恢复

状态：实现及开发验证完成，按正式发行门禁发布。范围仅 V2 本地 OCI 上传链路；平台 Registry 和上传回执继续拥有远端状态。

## 证据与决定

`publishBackendImage` 成功导出 OCI 后，无论上传结果如何，finally 都删除目录。传输中断后重建可能改变摘要，平台已保存的原分块因此无法复用。恢复应成为原 `openxiangda deploy` 的内部行为，不要求应用找 BuildKit 历史、手工上传或绕过发布规则。

本地维护短期制品缓存，不维护第二份部署状态。缓存键绑定实际平台、当前 tenant/user、应用、环境、工具版本、编译配置、工作区真实路径及 Docker 构建上下文摘要。身份取现有 whoami，上传每次仍由平台鉴权；不持久化 token 或身份正文。重试先验证所有 OCI 摘要，再向平台按原 manifest digest 发起 begin，使用服务器已有 offsets/ready 回执继续。没有独立的 SDK session ID；该协议的原操作键就是租户/应用内 manifest digest。

构建上下文按 Dockerfile 专用 ignore 优先、否则根 .dockerignore 计算，包含文件内容、路径、权限和符号链接目标。使用固定版本 Docker ignore 解析器，禁止通过 Git SHA 推断 dirty 工作区相同。构建前后摘要不同则不上传；这只是漂移检测，不宣称本机并发编辑下的源码快照证明。与原构建一样，远程 FROM/RUN 输入只在一次构建时求值；原制品恢复不会重新求值。

## 并发、边界和回滚

- 本机缓存位于用户私有目录，制品目录 0700、描述文件 0600；路径不接受远端输入，不跟随缓存符号链接。单候选心跳租约阻止同时上传，全局目录租约仅保护容量管理；固定 proper-lockfile 4.1.2 每 30 秒续约，失联 5 分钟后才允许接管。租约丢失停止后续网络请求，不删除新持有者文件。进程中断后可恢复原已封存制品。未封存构建残留可删除重建，绝不把不完整 OCI 当成已上传候选。
- 最多 8 个槽、按平台单镜像上限预留且总保留预算 8 GiB、每候选最多 8 GiB、24 小时；活动候选不可清理。清理仅限本 SDK 私有目录中的验证过的缓存记录，绝不扫描或删除 BuildKit/用户目录。额度不足且全部被活动候选占用时返回明确本机忙/容量错误，不删除他人正在使用的候选。
- OCI 封存前与每次上传前校验 manifest、所有 blob 和大小；持久记录在网络调用之前原子写入。已上传响应丢失时保留原目录，重试服务器 begin 的 ready 结果即可恢复。成功后删除缓存失败不得把远端成功改成失败。
- 文件树遍历、字节数、候选数、TTL 有界；不打印原始 Docker/网络错误、登录态、客户正文。上下文最多 100000 条目、8 GiB、60 秒，OCI 仅接受规范目录和引用 blob，防止未引用文件绕过保留预算。错误提供脱敏候选 ID、digest、过期时间和原错误码，仍使用普通 deploy 重试。
- 对不提供恢复身份的内部/旧调用保持临时上传路径；真实发布入口必须提供身份绑定。平台配置大于 8 GiB 的单镜像配额时维持原临时上传路径，不因本地缓存降低允许的镜像额度。稳定 1.x、前端无后端应用和 Registry 直推路径不改变。回滚 SDK 只会丧失缓存恢复能力，远端原摘要及分块仍由平台保留。

## 可证伪验证

真实临时文件 + 执行型假 Docker：首轮已保存分块后连续断网，第二轮 Docker 不可用仍从原摘要恢复，构建次数保持 1；complete 响应未知后从 ready 恢复；源码/租户/用户/平台/环境变化不能复用；篡改 blob/描述和符号链接拒绝且零网络；同时调用单写；死进程已封存候选可恢复；过期/配额清理不碰活动候选；成功删除失败保持成功。验证既有 gzip/8 MiB 传输协议和主线正式发行门禁。

2026-09-26 开发验证：10 项候选恢复、7 项现有上传测试通过；最终 `verify:affected` 20/20 任务通过，devkit 380 项、CLI login → create → dev → check → deploy → status → logs → rollback 实际执行通过。真实 Docker Buildx 导出发现并兼容空 `ingest` 暂存目录，仍拒绝非空目录及未引用 blob。独立真实 Buildx 导出后注入上传失败，再把 Docker 路径设为不存在，第二次调用成功读回相同 `sha256:8bfc7e53051f7c6c03974f756c65a69acc7b85873663d9cfa36788611ae4a761`；begin 两次、缓存清理完成。该验证的远端回执为受控协议替身，不是客户应用发布证明。

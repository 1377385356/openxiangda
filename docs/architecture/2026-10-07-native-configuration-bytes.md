# Native 多流程配置字节预算

状态：实施中。主题 C63；2026-10-07。

## 问题与所有者

本地 workflow-lab 财务五流程源码联调的 canonical 配置为 4,222,073 字节、
契约为 1,076,039 字节；在任何配置激活或 DDL 前触发
`OPENXIANGDA_CONNECTED_DEV_CONFIGURATION_TOO_LARGE`。大应用的声明与 JSON
节点已有独立有界扩容，但 4 MiB 配置上限仍阻断真实字段与任务页。

contracts sealed compiler 是配置验证、容量与能力需求的所有者；devkit 将同一
规则用于正规化配置，Server 的同步、覆盖层与交付入口执行相同字节预算。
应用不拆分权限事实、不裁剪业务字段，也不绕过 Native 编译。

## 决定与不变量

配置 canonical 上限由 4 MiB 扩到 8 MiB，契约上限仍 8 MiB。仅配置超过旧
4 MiB 时派生 `application.extended-configuration-bytes:1.0.0`；普通配置不增
需求，旧站点不支持时在上传前明确拒绝。正规化完成后按实际 UTF-8 canonical
字节派生，不能使用源声明长度或由契约自行声称支持。

HTTP／连接开发请求合计仍最多 10 MiB；单字符串 1 MiB、深度 40、JSON 节点
预算、任务页 64 KiB、单表／子表／分页限制不变。增加配置预算不意味着每项
同时可占满；请求总预算独立约束。

## 失败、并发与影响

超上限仍在摘要、语义编译与任何制品写入／DDL／激活前拒绝；权限、CAS、幂等
与原结果恢复不变。不引入新状态或数据 API，不影响 1.x。其他租户与生产只有
明确协商新能力的较大 V2 配置可使用新增空间；不自动激活应用或修改正式组合。

## 回滚与可证伪验证

SDK／Server 分别可回退；已使用新能力的应用必须退回 <=4 MiB 的原配置后再
回退能力。验证 ESM／CJS 配置编译与能力需求一致、小配置不增能力、恰好上限
与多一个 UTF-8 字节的拒绝、旧／禁用能力拒绝，以及请求总预算拒绝前无写入。
只跑本主题相关检查，联调仍使用源码，不发布 npm 或冻结实验平台组合。

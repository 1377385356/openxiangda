Replace the minimal rich text editor with the free MIT Tiptap 3.31.4 engine on
PC and mobile. Preserve bounded typography, colors, alignment, indentation,
tables, task lists and superscript/subscript through one HTML5 safety policy
used by editing, Native writes and public projections. Add managed MP4/WebM
video references, bounded uploads and existing cross-resource file-copy grants.
Applications with text.rich automatically require the paired data.rich-text
platform capability; existing HTML values stay in the same storage field.

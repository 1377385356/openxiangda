Make semantic data fields one strict 2.0 contract across local checks and
deployment: single directory users use string IDs, single departments and
resource references use UUIDs, multi-value references use JSON, managed-file
limits are bounded, and directory protocol requirements derive from resource
declarations. No legacy field type is translated.

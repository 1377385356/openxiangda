Add compiler-sealed named-operation Workflow submission surfaces for the standard
PC and mobile launch routes. Applications can now preserve an original atomic
business action for create or existing-record submission, consume allowlisted
context prefills, and return an explicit no-approval result without synthesizing
a Workflow instance. The paired launch pages remain standalone user surfaces
without the admin Shell or an application business header.

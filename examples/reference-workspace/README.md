# Reference workspace skeleton

This is the M0 layout fixture for an OpenXiangda 2.0 application. It proves the
workspace boundary only; the independently versioned end-to-end reference
application will be created after the platform Data/AuthZ and runtime packages
exist.

```text
apps/web      React application package
apps/server   NestJS application package
platform      Data/AuthZ/Event/Workflow source declarations
```

No 1.x form, page, function, automation or release resource is present.
